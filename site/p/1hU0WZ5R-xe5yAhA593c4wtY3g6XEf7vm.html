현장의 목소리

01

입력 부담

종이 신청서 → 수기 입력 반복
  • 농민이 종이 신청서 작성
  • 지도사가 ASTIS에 수기 재입력
  • 미생물 분석 = 최대 입력량
  • 센터 165개소 양식 모두 상이
  • 키오스크 도입은 일부 센터 한정
  • 한 건당 평균 5~10분 소요
AI → 스캔 → OCR + AI → 엑셀 자동 변환
02

이중 기록

현장 기록 → 복귀 후 재입력
  • 현장 상담 시 다이어리 수기 기록
  • 복귀 후 행정망에 동일 내용 재입력
  • 같은 내용을 두 번 쓰는 비효율
  • 인터넷망 입력 개발 중(미완)
  • 기록 누락·왜곡 가능성 발생
  • 일과 후 잔업으로 처리
AI → 음성 녹음 → 자동 전사 · 분류
03

데이터 활용난

쌓여 있지만 꺼내 쓸 수 없음
  • 수년간 축적된 상담·분석 데이터
  • 유사 민원 시 과거 이력 검색 어려움
  • 통계자료 수기 집계 의존
  • 데이터가 자산이 아닌 기록으로만
  • 신입 지도사 학습용 활용 불가
  • 정책 제안 근거자료 부족
AI → RAG 검색 + 자동 통계 리포트
