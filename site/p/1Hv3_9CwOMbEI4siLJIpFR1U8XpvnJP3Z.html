문제 정의

교감 선생님의
하루는 왜 이렇게 바쁜가

행정 업무가 교육 본질을 침식하는 3가지 구조적 문제

01
📨
공문 폭증과 분류 지옥
하루 평균 20~40건의 공문. 교육청·교육부·각 부서에서 쏟아지는 공문을 읽고, 분류하고, 담당자에게 전달하는 데만 2시간 이상이 소요됩니다. 중요한 공문을 놓치는 실수도 빈번합니다.
02
👁️
수업 관찰의 형식화
수업을 대충 진행하는 교사를 발견해도 체계적인 관찰 기록이 없으면 피드백이 어렵습니다. 매년 반복되는 형식적인 수업 참관으로는 실질적 개선을 이끌 수 없습니다.
03
📋
복무 관리의 사각지대
교직원 연가·조퇴·외출 현황을 수기로 관리하다 보니 오류가 생깁니다. 규정 위반을 사후에 발견하면 이미 패턴이 고착된 상태이고, 예방적 관리가 불가능합니다.
핵심 기능

AI가 대신 처리하는
3가지 핵심 업무

교감 선생님이 직접 겪는 세 가지 핵심 고통을 AI로 해결합니다.

MODULE 01
📨
AI 공문
자동 분류 시스템
Document AI

수신된 공문을 AI가 즉시 읽고 분류·요약·우선순위를 지정합니다. 담당 교사 자동 배정, 마감일 추출, 조치 필요 여부 판단까지 자동화됩니다.

→
3줄 요약 자동 생성20~30장 공문도 30초 안에 핵심만 추출. 읽을지 말지 판단 가능.
→
긴급도 자동 판별마감일·법령 근거·필수 조치 여부를 분석해 빨강/노랑/초록 3단계로 구분.
→
담당 부서 자동 배정공문 내용을 분석해 교무·연구·생활지도 등 담당 교사에게 자동 전달.
→
회신 초안 자동 작성표준 공문 양식에 맞춘 회신 초안을 AI가 먼저 작성, 교감은 검토·서명만.
MODULE 02
🔍
수업 관찰
AI 기록 분석
Teaching Quality

체계적인 수업 관찰 체크리스트와 AI 분석으로 교사별 수업 패턴을 시각화합니다. 감정이 아닌 데이터로 피드백하고, 개선 이력을 관리합니다.

→
구조화된 관찰 체크리스트학습목표 제시, 학생 참여도, 피드백 질 등 15개 항목으로 표준화된 관찰 기록.
→
교사별 시계열 분석1회성이 아닌 학기별 변화 추이 추적. 개선 여부를 수치로 확인.
→
AI 피드백 리포트 자동 생성관찰 데이터 기반으로 맞춤형 피드백 문서 초안을 생성해 면담 준비 시간 단축.
→
우수 수업 사례 아카이브잘하는 선생님의 방법론을 데이터로 쌓아 연수 자료로 활용.
MODULE 03
📅
교직원 복무
스마트 관리
HR Intelligence

교직원의 연가·조퇴·외출·출장 현황을 실시간으로 시각화합니다. 패턴 이상 감지, 규정 준수 여부 자동 체크로 사각지대를 없앱니다.

→
실시간 부재 현황 대시보드오늘 몇 명이 어디 있는지 한눈에. 수업 결손 위험 자동 알림.
→
이상 패턴 자동 감지특정 요일·기간에 반복되는 조퇴·결근 패턴을 AI가 먼저 포착해 알림.
→
연가 잔여일 자동 계산교직원별 연가 소진율, 잔여일, 사용 권장 시기를 자동 관리.
→
복무 규정 위반 사전 경보규정 상 허용 범위 초과 전에 사전 알림으로 갈등 없이 예방적 관리.
