같은 "AI"라는 단어를 쓰지만 실제 사용 방식은 해마다 달라졌습니다. 2023년에는 질문과 응답을 한 번 주고받는 방식이 주를 이뤘습니다. 2025년부터 한 번의 지시로 AI가 5~10단계를 스스로 진행하는 방식이 보편화됐습니다. 2026년 현재는 반복 업무에서 AI가 먼저 실행하고 사람이 승인·반려하는 구조가 일부 도입되기 시작했습니다. 조직마다 도입 단계가 다르기 때문에 "우리 회사가 어느 단계에 있는가"를 먼저 확인해야 나머지 논의가 진행됩니다.

AI 도입 수준을 논의할 때 업계에서 통용되는 네 단계 구분입니다. 같은 회사 안에서도 팀마다 단계가 다를 수 있으며, 단계별로 요구되는 교육·인프라·관리 방식이 달라집니다.

  • STAGE 01 · 2022—23
    Prompting. 단일 질문에 단일 응답. 번역·요약·초안 생성이 주요 용도. 개인 생산성은 향상되지만 업무 프로세스 자체는 변하지 않습니다.
  • STAGE 02 · 2024
    Workflow. 사람이 업무 절차를 설계하고 AI가 각 단계를 실행. n8n, Zapier, Make 같은 자동화 도구가 AI와 결합. 반복 업무의 상당 부분이 자동화됩니다.
  • STAGE 03 · 2025
    Agent. 목표만 주면 AI가 계획·실행·수정을 수행. Claude Code, Manus, Deep Research 등이 대표 사례. 직무의 경계가 재조정되기 시작합니다.

기술보다 조직 설계가 결정적이다

주요 모델은 모든 기업이 동일하게 사용할 수 있습니다. 도입 성과의 차이는 모델 선택이 아니라 프로세스 재설계와 인력 재배치에서 발생합니다. 도구 비교에 시간을 많이 쓰는 조직일수록 실제 변화가 지연됩니다.

측정은 속도가 아니라 새 업무로

"30% 빨라졌다"보다 기존에 불가능했던 업무를 수행하게 됐는가가 더 유효한 지표입니다. IP 사업의 핵심은 새로운 콘텐츠·상품·파이프라인 추가 여부입니다.

초기 6개월은 생산성이 하락할 수 있다

예산을 세 항목으로 분리

NotebookLM을 도입한다는 말만으로는 아무것도 움직이지 않습니다. 구체적 쓰임새가 있어야 조직이 움직입니다. 오늘 저녁부터 바로 쓸 수 있는 세 가지 벙커를 제안합니다. 첫째, 경쟁사 분기보고서 벙커: HYBE·SM·네이버·CJ ENM 공시를 한꺼번에 넣고 경쟁 모니터링 자동화. 둘째, 글로벌 리포트 벙커: McKinsey·BCG·Deloitte 리포트에서 반대 논거 강제 추출. 셋째, 내부 회의록 벙커: 6개월치 임원회의록에서 실행 안 된 항목만 자동 추려냄. 각각 10분 안에 세팅이 끝나고, 이 세 벙커만 돌려도 임원 브리핑의 질과 속도가 분명히 달라집니다.

BUNKER 01 · 경쟁 모니터링

경쟁사 분기보고서
벙커

HYBE·SM·네이버·CJ ENM의 공시자료 4분기치를 한꺼번에 업로드합니다. ① "지난 1년 AI 관련 언급 변화는?" ② "경쟁사 신사업 공통 키워드" ③ "우리 대비 언급 안 된 영역" ④ "경쟁사가 늘려가는 해외 지역". 경쟁 모니터링이 사람 1명 상근 → AI 5분으로 바뀝니다. 더 이상 실무자가 네 회사 공시 페이지를 돌며 수작업 요약할 필요가 없고, 임원이 받는 보고의 신선도가 분기 단위에서 실시간 단위로 이동합니다.

예: 매 분기 공시 발표일에 30분 안에 경쟁 비교 브리핑. 실무자 주간 리포트를 대체하고, 경쟁 대응 속도가 2배 이상 빨라집니다.
BUNKER 02 · 반대 논거

글로벌 리포트
벙커

McKinsey·BCG·Deloitte의 엔터·미디어 리포트 10~20편을 업로드합니다. 핵심 활용 포인트는 이것입니다. "우리 전략에 불리한 관점만 뽑아줘". 자기 전략을 뒷받침하는 근거만 찾는 것은 누구나 합니다. 반대 논거를 강제로 꺼내는 것이 전략 품질을 높입니다. ① 반대 시나리오 자동 생성 ② 글로벌 선례에서 실패 패턴 추출 ③ 우리 가정의 약점 식별 ④ 임원회의 발표 30분 전 실전 도구. 이 절차가 제도화되면 의사결정 실패율이 눈에 띄게 떨어집니다.

예: "이번 투자안의 5가지 실패 시나리오" → AI가 글로벌 리포트에서 근거 찾아옴. 반대 논거 수집이 제도화됩니다.

06 · Muscle 2 · Canvas

Canvas, 생각을 즉석에서 그린다.

머릿속 프레임을 말로 설명하면, 그 자리에서 다이어그램·표·매트릭스로 만듭니다.

한 줄 프롬프트 = 슬라이드 한 장

"우리 사업을 BCG로 그려줘", "Ansoff로 글로벌 옵션 4개". Gemini Canvas·Claude Artifacts·ChatGPT Canvas 모두 가능하다.

컨설팅 펌과의 차이

컨설팅: 2주, 수천만 원. Canvas: 2분, 거의 무료. 깊이는 다르지만 일상 의사결정엔 Canvas가 압도적이다.

Canvas가 진짜 대체하는 것

컨설팅 펌의 최종 보고서가 아니라, 매일 발생하는 작은 의사결정의 해상도다.

임원이 외워둘 다섯 프레임

BCG · Ansoff · 3 Horizons · Porter · Pre-mortem. 나머지는 AI에게. 경영자 판단은 "어떤 프레임을 꺼내 쓸지"뿐이다.

다음 임원회의에서 한 번은 반드시 Canvas로 프레임을 즉석에서 그려보세요. 직접 해 보면 이해됩니다. 안 써본 임원은 지시할 언어가 생기지 않습니다.

06 · Muscle 3 · Agent

Agent, 도구를 만드는 AI.

앞의 둘이 "쓰는" 쪽이라면 이건 "만드는" 쪽. 도구 자체를 AI가 만들어줍니다.

Claude Code · Codex의 실체

터미널에서 도는 AI 에이전트. "이런 도구 만들어줘" 하면 실제로 파일을 만들고 코드를 쓰고 오류를 고치고 테스트까지 수행한다.

외주 개발 2주 → 현장에서 3분. 비개발자는 Claude Code 터미널이나 Claude Artifacts로 접근.

경영자가 얻는 진짜 가치

개인 비서가 엑셀 대신 짜주던 수준이 아니다. 의사결정 패턴 자체가 시스템화된다.

"내 머릿속 체크리스트"가 조직 자산으로. 후임에게 엑셀이 아니라 에이전트를 인수인계한다.

경영자의 새 의무 — "월 1회는 직접 에이전트를 써본다". 안 써본 임원은 지시할 언어도, 위임할 판단도, 검증할 근거도 갖지 못합니다.

06 · Demo 1 · Pre-mortem

데모 하나: Pre-mortem 도구.

새 사업 결정 직전에 쓰는 도구. AI가 강제로 "이 결정이 실패한다면 왜"를 5가지로 제시.

Step 1의사결정 한 줄 입력

"일본에 드라마 제작 법인을 단독 설립한다" 같은 의사결정을 한 문장으로.

Step 2실패 시나리오 5개 자동 생성

각 시나리오별로 원인 · 조기 감지 신호 · 대응책을 AI가 자동으로 채워넣는다.

Step 3반대 논거 + 유사 사례

임원 회의에서 아무도 말하지 않은 "악마의 변호인" 의견이 강제로 꺼내진다. 과거 유사 실패 사례 3~5건을 자동 검색해 패턴 비교 제공.

Step 4사전 점검 체크리스트

결정을 유지하더라도 사전에 점검할 10개 항목이 자동 출력된다. 이 체크리스트가 곧 리스크 관리의 기준선이 된다.

제작 시간 — 약 30분. Claude Code 프롬프트 한 번으로 HTML 툴 완성. 실전 적용: 분기 전략회의의 공식 절차로 등재. Pre-mortem 안 거친 안건은 회의에 못 올라오게.

06 · Demo 2 · IP Dashboard

데모 둘: IP 포트폴리오 대시보드.

주요 IP를 거품차트로 시각화. 수익·성장률·투자액 세 축을 한눈에.

기능 1거품차트 한 장으로 전체 보기

X축 = 수익, Y축 = 성장률, 원 크기 = 투자액. 포트폴리오 건전성을 한 장으로 파악. 분기별 슬라이더로 시간 이동도 가능.

기능 2드래그 시뮬레이션

원을 드래그로 이동하면 전체 포트폴리오 기댓값이 실시간 재계산. 엑셀 한 시간 작업이 마우스 한 번. 회의 중 즉석 "만약 이렇게 돌리면?" 시나리오가 가능하다.

기능 3AI 코멘트 버튼

"이 포트폴리오의 가장 큰 리스크는?" 누르면 Claude API 호출 → 분석 의견을 붙여준다. 데이터와 AI 해석이 한 화면에서 동시에 움직인다.

이게 진짜 "AI를 경영에 쓴다"의 모양입니다. 프롬프트 몇 번이 아니라, 내가 반복해 쓰는 도구 자체가 AI로 움직이는 상태. 이 차이를 체감한 뒤에 다음 투자 결정을 하십시오.

CLOSING · 요약

핵심 요약 세 가지

오늘 내용의 요지입니다. 후속 논의와 실행 계획의 출발점으로 활용하실 수 있습니다.

01AI 도입은 네 단계로 구분된다

Prompting, Workflow, Agent, Agentic AI. 조직 내 팀별로 현재 단계가 다를 수 있으며, 각 단계에 필요한 교육·예산·관리 방식이 다릅니다. 현재 단계 파악이 도입 논의의 전제입니다.

02엔터 산업은 AI 영향 초기 대응 필요 영역이다

기획, 제작, 배급·마케팅, 팬덤, 글로벌 다섯 영역이 동시에 영향권에 들어와 있습니다. 특정 영역만 대응하면 다른 영역에서 경쟁력 격차가 발생하므로 병렬 대응 계획이 필요합니다.

03AI 도구는 용도별로 분리해서 도입한다

정보 소화용(NotebookLM, Deep Research), 시각화용(Canvas, Artifacts), 도구 제작용(Claude Code, Codex)은 목적과 사용자가 다릅니다. 각 영역별로 담당 부서·예산·성과 지표를 분리하는 것이 정착률을 높입니다.

실무 이관 시 확인할 여덟 가지

실무 부서에 전달할 때 확인 사항으로 사용하실 수 있는 질문 목록입니다.

  • 각 팀의 AI 도입 단계가 파악되어 있는가. 팀장 보고를 통해 현재 단계를 문서화.
  • 경쟁사 공시 모니터링에 AI 도구가 도입되어 있는가. 미도입 시 NotebookLM 등 도구 검토.
  • 아티스트·작가 계약서에 AI 학습·생성 조항이 반영되어 있는가. 기존 계약 재검토 필요.
  • 글로벌 번역·더빙 프로세스가 AI 중심으로 재설계되어 있는가. 외주 중심이면 6개월 내 전환 검토.
  • 사내 AI 교육이 임원급부터 시작되었는가. 임원이 도구 경험 없이는 의사결정 어려움.

  • AI 거버넌스가 국내·일본·북미별로 별도 정의되어 있는가. 지역별 규제·문화 차이 고려.
