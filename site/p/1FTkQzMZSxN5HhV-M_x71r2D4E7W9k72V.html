HOW GENERATIVE AI IS USED

코드를 배우는 과정이 아니라 업무 도구를 만드는 과정입니다

URL을 붙여넣으면 SEO 점검표가 나오고, Excel 파일을 선택하면 검색광고와 CRM 분석표가 만들어집니다.

교육생은 코딩 문법을 외우거나 코드를 처음부터 작성하지 않습니다. 하고 싶은 업무를 Copilot에 말로 설명하고, Copilot이 작성한 코드를 준비된 실행 화면에 붙여넣습니다.

수강생이 하는 일은 입력할 URL이나 Excel 파일을 고르고 실행 버튼을 누르는 것입니다. 오류가 나오면 오류 문장을 그대로 복사해 Copilot에 보여주고 수정된 코드를 다시 붙여넣습니다.

수강생이 직접 하는 일

  • 분석할 URL이나 Excel 파일 선택
  • Copilot 답변의 코드를 복사
  • 실행 버튼을 누르고 결과 확인

Copilot이 대신 도와주는 일

  • 필요한 코드를 처음부터 작성
  • 오류 원인을 쉬운 말로 설명
  • 결과를 표·차트·보고 문장으로 정리
수강생이 기억할 세 가지

① URL이나 Excel 파일을 고릅니다　② Copilot이 준 코드를 붙여넣습니다　③ 실행 버튼을 누르고 결과 Excel을 엽니다

한계 Copilot이 만든 코드와 분석 결과는 정답을 보장하지 않습니다. 원본 건수, 합계, 표본 행과 결과 파일을 사람이 확인해야 합니다.
