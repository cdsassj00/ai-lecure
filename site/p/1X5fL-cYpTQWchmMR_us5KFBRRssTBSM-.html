[이론] 엑셀과 구글 스프레드시트 — 무엇이 다른가

구글 스프레드시트는 설치하는 프로그램이 아니라 브라우저에서 여는 서비스입니다. 화면은 비슷해 보이지만 협업·저장·버전 관리가 근본적으로 다르게 동작합니다.

1
실시간 공동 편집CO-EDIT

여러 명이 같은 파일을 동시에 편집합니다. 파일을 주고받으며 이름을 바꿔 저장할 필요가 없습니다. 예 — 팀원이 입력하는 값이 내 화면에 바로 보입니다.

2
자동 저장 · 버전 기록AUTOSAVE

저장 버튼이 없습니다. 모든 변경이 즉시 저장되고, 시점별로 되돌릴 수 있습니다. 예 — 어제 오전 상태로 복원할 수 있습니다.

3
Gemini 사이드패널GEMINI

시트 우측 ✦ 아이콘으로 AI 패널을 엽니다. 시트 내용을 요약·질문하거나 표를 만들어 달라고 할 수 있습니다.

엑셀 파일을 가져오는 두 가지 방법
방법 A · 그대로 열기
드라이브에 올려서 열기

.xlsx를 드래그해 업로드하면 엑셀 형식 그대로 열립니다. 제목 옆에 .XLSX 배지가 붙습니다.

▼ 구글 전용 기능을 쓰려면
방법 B · 변환
Google Sheets로 저장

파일 > Google Sheets로 저장을 누르면 변환됩니다. 스마트칩·구글 전용 함수를 온전히 쓸 수 있습니다.

[개념] 구글 전용 3대 함수 — 무엇을 할 수 있는가

세 함수가 각각 무엇을 할 수 있는지만 알면 됩니다. 그래야 Gemini에 무엇을 요청할지 알 수 있습니다. 수식 문법은 외우지 않습니다.

1
QUERYSQL식 집계

표에서 원하는 열을 골라 조건으로 걸러 내고 합계를 냅니다. 예 — "장르별 조회수 합계를 높은 순으로" 한 줄로 처리.

2
IMPORTRANGE시트 연결

다른 시트의 데이터를 실시간으로 끌어옵니다. 예 — 팀원 3명의 시트를 하나로 자동 취합.

3
ARRAYFORMULA수식 확장

한 셀에 쓴 수식을 열 전체에 자동 적용합니다. 예 — 새 행이 들어와도 수식을 다시 복사할 필요 없음.

QUERY 한 줄이 대체하는 것
기존 방식
필터 + 정렬 + 피벗 + 합계

메뉴를 여러 번 눌러 단계별로 처리합니다. 데이터가 바뀌면 다시 해야 합니다.

▼ 한 줄로
QUERY 방식
=QUERY(범위, "조건")

조건을 문장처럼 적으면 결과가 자동으로 갱신됩니다. 데이터가 바뀌어도 그대로 유지됩니다.

정리

세 함수의 쓰임새만 파악하면 됩니다. 실제 수식은 다음 단계에서 Gemini에게 자연어로 요청해 받습니다.

[실전] QUERY 활용 — 대표 3패턴

QUERY는 표를 데이터베이스처럼 다룹니다. 아래 세 패턴만 알면 대부분의 집계·조회가 해결됩니다. 문법은 Gemini에 요청하되, 무엇을 뽑는 패턴인지는 알아 둡니다.

패턴수식 예시무엇을 하는가
골라 보기
SELECT		=QUERY(A:E, "select A, C where C > 1000")필요한 열만 골라, 조건에 맞는 행만 뽑습니다. 예 — 조회수 1000 이상 작품만.
묶어 합치기
GROUP BY		=QUERY(A:E, "select B, sum(D) group by B")같은 항목끼리 묶어 합계·평균을 냅니다. 예 — 장르별 조회수 합계.
정렬해 보기
ORDER BY		=QUERY(A:E, "select B, sum(D) group by B order by sum(D) desc")집계 결과를 큰 순서로 정렬합니다. 예 — 인기 장르 순위표.
요청 팁

Gemini에는 이렇게 적습니다 — "작품 시트에서 장르별 조회수 합계를 높은 순으로 QUERY로 만들어 줘". 열 위치(A, D)는 실제 시트에 맞게 바꿔 줍니다.

[실전] IMPORTRANGE · ARRAYFORMULA — 여러 시트를 하나로

팀원이 각자 관리하는 시트를 하나로 모아 한 번에 집계하는 상황이 가장 흔합니다. 이때 두 함수를 함께 씁니다.

1
IMPORTRANGE시트 연결

=IMPORTRANGE("시트URL", "시트1!A:E")
다른 파일의 범위를 실시간으로 끌어옵니다. 원본이 바뀌면 자동으로 갱신됩니다. 처음 한 번은 액세스 허용을 눌러야 합니다.

2
ARRAYFORMULA수식 확장

=ARRAYFORMULA(C2:C * D2:D)
한 셀 수식을 열 전체에 자동 적용합니다. 새 행이 들어와도 수식을 다시 복사할 필요가 없습니다.

세 팀 시트를 하나로 취합하는 구조
원본 · 팀별 시트
A팀 · B팀 · C팀 시트

각 팀이 자기 시트에만 입력합니다. 서로의 시트를 건드리지 않습니다.

▼ IMPORTRANGE 로 끌어오기
취합 · 통합 시트
전체 현황판 한 장

세 시트가 한 곳에 실시간으로 모입니다. 여기서 QUERY로 전체를 집계합니다.

정리

IMPORTRANGE로 모으고, ARRAYFORMULA로 계산을 자동 확장하고, QUERY로 집계합니다. 세 함수가 하나의 흐름을 이룹니다.

[개념] Apps Script 자동화 — 시트를 데이터베이스로

Apps Script는 구글의 자동화 스크립트 환경입니다. 엑셀의 매크로(VBA)에 해당합니다. 코드는 생성형 AI로 작성하고, 메뉴 버튼으로 실행합니다.

1
AI가 코드 작성SCRIPT

"완료된 행을 다른 시트로 옮기는 코드를 만들어 줘"라고 요청하면 스크립트를 받습니다. 예 — 메일 자동 발송, 행 이동.

강의 요약

01

기본 조작은 엑셀과 비슷하므로, 이 과정은 구글 전용 함수와 생성형 AI에 집중합니다.

02

구글 전용 3대 함수 QUERY·IMPORTRANGE·ARRAYFORMULA는 쓰임새만 알면, 수식은 Gemini에 요청해 받습니다.

03

텍스트 요약·분류·번역은 =AI() 함수로 셀 안에서 일괄 처리합니다.

04

Apps Script로 자동화하고, 구글 시트를 데이터베이스 삼아 작은 웹앱을 서버 없이 운영합니다.

05

마지막에 현업 데이터로 대시보드를 완성해 웹 게시까지 마칩니다.
