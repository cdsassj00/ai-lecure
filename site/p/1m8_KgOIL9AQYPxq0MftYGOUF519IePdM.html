결과 확인
결과를 확인하는 관점과 주의할 점
AI가 만든 결과는 원본 자료와 비교하며 확인하고, 외부로 나가는 행동은 사람이 결정합니다.
확인 1구성참고 제안서의 순서와 형식을 따르되 문장을 그대로 옮기지 않았는지 봅니다.
확인 2사실제품 사이트에 없는 기능·수치·고객 실적을 만들어 넣지 않았는지 봅니다.
확인 3숫자가격·수량·합계·세금 조건이 표와 본문에서 같은지 봅니다.
확인 4출력PDF의 모든 쪽이 글꼴 깨짐·잘림·겹침 없이 열리는지 봅니다.
