파이썬 콘솔 (REPL)

아무 파이썬 코드나 실행해 보세요. 마지막 줄의 값은 자동으로 출력됩니다. Ctrl+Enter로 실행.

NumPy · pandas

설치에 몇 분 걸리던 데이터 분석 스택이 버튼 하나로 로드됩니다. import pandas가 성공하는 순간을 보세요.

Matplotlib 차트

파이썬으로 그린 그래프가 PNG 이미지로 즉석 렌더링됩니다. (브라우저 환경엔 한글 폰트가 없어 라벨은 영문)

CSV 분석기

CSV를 던지면 pandas가 구조를 파악하고 기술통계를 냅니다. 엑셀이 저장한 한글 CSV(EUC-KR)도 인코딩을 자동 감지합니다. 파일은 서버로 가지 않습니다 — 전부 이 탭 안에서 끝.

CSV 파일을 여기로 드래그하거나 클릭해서 선택

패키지 설치 (micropip)

pip의 브라우저 버전. 순수 파이썬 패키지를 PyPI에서 즉석 설치합니다.

추천 체험: cowsay(소가 말함) · emoji · python-dateutil — C 확장이 필요한 패키지는 Pyodide가 미리 빌드한 목록에 있어야 합니다. 주의: 이 탭만은 PyPI 인터넷 접속이 필요해서 폐쇄망에서는 동작하지 않습니다 (numpy·pandas·matplotlib은 로컬 배포본에 포함이라 오프라인 OK).

JS ↔ Python 상호운용

두 언어가 한 메모리 안에 삽니다. 파이썬이 웹페이지를 직접 만지고, JS 데이터가 파이썬으로 넘어갑니다.

← 이 상자를 파이썬이 조작합니다

가상 파일시스템

Pyodide 안에는 메모리로 만든 리눅스식 파일시스템이 있습니다. 파이썬이 쓴 파일을 진짜 PC로 다운로드할 수도 있어요.

엑셀 (openpyxl)

한글 다음으로 흔한 공공 파일 포맷. 엑셀 프로그램 없이 .xlsx를 만들고 읽습니다 — openpyxl은 full 배포본 포함이라 폐쇄망 OK.

통계 검정 · 머신러닝

scipy와 scikit-learn — 논문에서 쓰는 그 라이브러리가 브라우저에서 돕니다. "민원 처리 개편이 정말 효과가 있었나?"를 숫자로 답하기.

수식 계산 (SymPy)

숫자가 아니라 수식 자체를 다루는 기호 계산. 방정식 풀이·인수분해·미분·적분을 한 번에.

x가 들어간 식이면 뭐든 됩니다. 예: sin(x)*x, x**3 - 1, exp(x)/x

이미지 처리 (Pillow)

포토샵 없이 파이썬으로 픽셀을 만집니다. 사진을 고르면 흑백·윤곽선 변환을 즉석에서 — 이미지는 밖으로 안 나갑니다.

HTML·XML 파싱 (BeautifulSoup + lxml)

문서 덩어리에서 원하는 것만 뽑아내는 도구. 게시판 HTML에서 표를 긁어 DataFrame으로 — 축 F의 HWPX(=XML) 해부로 가는 징검다리.

오프라인 패키지 카탈로그

full 배포본에 미리 빌드돼 들어있는 대표 패키지들 — 전부 폐쇄망에서 loadPackage 한 줄로 로드됩니다. 골라서 즉석 로드 테스트를 해보세요.

문서: HWPX 해부 · Word 생성

한글 파일(HWPX)과 워드 파일(DOCX)의 정체는 ZIP + XML. 해부에는 파이썬 표준 내장(zipfile·re)만 쓰므로 추가 라이브러리 0, 폐쇄망 무조건 OK입니다.

해부기: 파일을 넣으면 내부 ZIP 목록과 본문 텍스트(<hp:t> / <w:t>)를 추출합니다 — 한글·워드 프로그램 없이. Word 생성: python-docx는 순수 파이썬이라 온라인은 micropip으로, 폐쇄망은 휠 파일을 ./libs/wheels/에 반입해 설치합니다.

템플릿 보존 방식 — HWPX 찾아바꾸기 생성기

해부의 다음 단계는 생성입니다. 원본 .hwpx를 통째로 품고 본문 텍스트만 치환한 뒤 ZIP으로 재조립 — cdsahwpx의 원리를 파이썬 20줄로. 표준 내장만 사용, 폐쇄망 OK.

템플릿 없음
