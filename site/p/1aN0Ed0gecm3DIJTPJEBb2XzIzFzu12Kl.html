[강사] 더닝-크루거 곡선 · 학습 루틴

자신감 곡선으로 보는 강사의 학습 위치와 루틴

에이전트·스킬·하네스 같은 용어가 쏟아질 때 이미 안다고 느끼는 구간에 머물면 공부를 멈추게 됩니다.

흔히 도는 변형 곡선 대신 원 논문의 그래프를 보여 줍니다. 익숙한 개념을 새롭게 보이게 하는 방법은 원전을 찾는 것입니다.
강사의 학습 루틴
  1. 신모델은 2~3일 안에 직접 설치·사용합니다. 못 했다면 AI에 대한 자신의 관심과 투입 시간을 점검합니다.
  2. 하루 1~2시간 AI에 몰입하는 시간을 확보합니다.
  3. 자기만의 그래프 1개를 준비합니다. 가장 좋은 소스는 논문 원전입니다.
  4. 개념어를 모읍니다. ‘스크롤 스크럽’처럼 이름을 알면 How는 AI에 맡길 수 있습니다.
  5. 음성으로 기록합니다. 이동 중 AI와 토론하며 생각을 전사해 강의 자산으로 쌓습니다.
강사용 큐강사 자신도 곡선의 어느 지점에 있는지 먼저 밝힙니다. 겸손한 자기 위치 설정이 수강생과의 거리를 줄입니다.
핵심구현 방법(How)은 AI가 상당 부분 대신합니다. 강사의 몫은 개념(What)과 이유(Why)를 설명하고, 구현은 AI와 함께 보여 주는 것입니다.

③ 기술 버전이 아니라 원리. AI가 바뀌어도 따라갈 수 있게 합니다.

④ 애자일. 프롬프트 → 컨텍스트 → 하네스로 흐르는데 공공 교육은 프롬프트에 멈춰 있습니다. 교재는 주 단위로 바뀐다고 전제합니다.

예 — LLM만 있으면 다 할 수 있다는 생각부터 바로잡습니다. LLM은 단어를 조합해 문장을 만들어 주는 모델입니다.

오해확인할 수 있는 증거교정된 이해
첨부하면 AI가 학습한다→새 데이터로 선을 다시 그리려면 모델을 바꿔야 하고, 질문마다 모델을 바꾸면 비용이 막대함. 최신 월드컵 결과를 모름→모델은 바뀌지 않는다. 다만 서비스 저장소·메모리에 남는 것은 별개로 판단

강사용 큐틀린 상식을 먼저 말하게 한 뒤 뒤집습니다. 첨부하면 학습한다는 말이 맞는지 틀린지부터 묻습니다.

[시연] 객관식 메타 프롬프트 · 회상과 재인

주관식 대신 객관식 — 이미지 프롬프트를 AI가 짓게 하기

힌트 없이 떠올리는 회상은 어렵고, 선택지를 보고 알아보는 재인은 쉽습니다. 메타 프롬프트를 객관식으로 유도합니다.

STAGE · 메타 프롬프트 입력문(요지)
절대 이미지 먼저 그리지 마. 내가 대충 그리고 싶은 내용을 이야기하면 객관식 십지선다형으로 다섯 문제로 내 이미지를 구체화해 줘. 구체화되면 전문 포토그래퍼의 카메라 설정 항목을 십지선다형으로 쉽게 풀어서 문제 내 줘. 내가 답변 다 하면 그 이미지를 그릴 수 있는 프롬프트를 줘.
선택 흐름(예시)
뉴스 보도용 사진30~50대 실무 연령노트북으로 ChatGPT 실습교육생 사이 카메라자연광·영화적 명암앞줄 선명16:9

[컨텍스트] 스킬 해부 · 구조와 설치

스킬 = 프롬프트 묶음 — 파일 구조와 설치 위치

예전에는 잘 만든 프롬프트를 글로 보내 줬다면, 이제는 MD 문서 + 실행 코드 + 참고 템플릿을 압축파일로 묶어 줍니다.

hwpx-mois-format.skill ← 압축 파일(zip으로 바꿔 열기)
├─ SKILL.md 1
│   name · description · 작성 지침
├─ scripts/ 2
│   HWPX 생성 파이썬 코드
├─ references/ 3
│   행안부 표준서식 규칙 · 예시
└─ 템플릿 파일
설치 위치 4
C:\Users\(이름)\.codex\skills — ChatGPT 앱·Codex
C:\Users\(이름)\.agents\skills — 여러 하네스 공용(글로벌)
1SKILL.md = 구체적인 명세LLM이 못 하거나 어설프게 하는 일의 지침. 양식뿐 아니라 질문 → 종합 → 생성 절차를 적습니다.
2scripts = 실행 코드Chat은 파이썬 의존이 커서 결과가 깨지고 Work는 정상 — 스킬은 Work에서 씁니다.
3references = 기관 원본원본은 HWPX로 확보합니다. HWPX는 XML이라 AI가 서식을 쉽게 읽습니다.
4전역 vs 프로젝트프로젝트 = 명령을 실행한 그 폴더. 앱에는 압축을 푼 폴더째 넣고 재시작합니다.
스킬 깎기‘채팅으로 만들기’ → 샘플 HWPX 첨부 → 1차 결과 비교 → ‘이렇게 바꿔 줘’ 반복 → ‘스킬로 등록해 줘’. 사례: 경찰청 보도자료 스킬.

  • ChatGPT는 커넥터를 플러그인과 같은 메뉴로 묶음

[실습] 사람 하네스 · 폐쇄망 경로

하네스가 없는 폐쇄망에서 사람이 하네스 역할 하기

하네스가 없는 환경에서는 사람이 하네스 역할을 맡아야 합니다. LLM에게 명령어를 받아 사람이 실행합니다.

목표
웹 LLM이 혼자서는 결코 할 수 없는 내 PC 작업을, 코드를 받아 사람이 실행해 해낸다
입력
바탕화면의 폴더들, 명령창(CMD·PowerShell), ChatGPT 무료 또는 즉시 응답 모드
프롬프트 요지
‘내 컴퓨터 바탕화면의 모든 폴더를 한 폴더로 모으는 명령어, CMD’ → 실행 후 ‘방금 모은 폴더를 원상복구하는 명령어’
핵심 행동
  1. 언어를 명시해 요청(CMD인지 PowerShell인지)
  2. 명령을 복사해 명령창에 붙여 넣고 실행
  3. 원상복구 명령도 받아 실행해 되돌려 본다
  4. PowerShell 업무 자동화 아이디어 50개에서 하나를 골라 .ps1로 저장·실행
관찰 · 완료 신호
폴더가 모였다가 되돌아오면 완료. .ps1 파일 또는 실행 화면 캡처를 단톡방에 제출(텍스트만 올리면 확인이 어려움)
큐괄호 부분은 수강생 업무로 채우게 하고, 잘 된 것만 공유합니다.
폐쇄망 질문 대응
폐쇄망에서는 어떻게 하느냐는 질문은 반드시 나옵니다. 보안성 검사를 거치지 않은 하네스 반입은 불가하므로, 외부망 LLM에서 CMD·PowerShell·Python 코드만 받아 사람이 실행합니다. 폐쇄망 PC에도 PowerShell은 있습니다(버전 차이 있음).
아이디어 프롬프트파워셸을 가지고 (내 업무) 자동화를 할 수 있는 아이디어 50개 → 예: 사진 촬영일 기준 자동 분류 · 여러 프로그램 한 번에 실행 · 네트워크 연결 테스트

[데이터] 싱크 맞추기 · 마법의 프롬프트

머리글과 두 줄로 AI와 데이터 구조를 맞추는 방법

파이썬 코드를 쓰는 데 데이터 전체는 필요 없고, 열과 열의 구조만 알면 됩니다 — Receive Code, Run Local
