    PART 1 · 에이전트의 원리

    무게중심이 '답변 생성'에서 '업무 실행'으로 옮겨간다

    챗봇의 시대, 프롬프트의 시대가 막을 내리는 중 — 기업 AI팀은 지금 에이전트 시스템을 설계하고 있다.
    1단계 · 2023

    챗봇

    질문하면 답변 텍스트를 받는다. 요약·번역·초안까지.

    한계 — 결과가 대화창을 못 벗어난다
    2단계 · 2024

    코파일럿

    문서·시트·메일 안에서 보조한다. 지금 사내 공식 도구가 여기.

    한계 — 그 프로그램 안에서만 작동
    3단계 · 2025~ — 지금 여기

    코딩 에이전트 하네스

    LLM이 내 PC의 파일·프로그램을 직접 실행한다. 개발자를 넘어 사무직으로 확산 중.

    전환 — 판도를 흔드는 중
    4단계 · 도입 대기

    사내 에이전트

    보안 검토가 관문. 기업 AI팀들이 이 시스템을 구상·상상·개발하고 있다.

    준비 — 먼저 써 본 사람이 기준을 만든다
    현실

    PART 3 · 영역 1

    PowerShell·CMD — 윈도우에서 자동화할 수 있는 것

    .ps1
    말로 요청 → 명령 생성 → 터미널에 붙여넣기 → 실행. 설치할 것이 없다 — 모든 윈도우 PC가 대상.
    파일 · 폴더정리의 자동화
  • 다운로드·바탕화면 월별·유형별 자동 정리
  • 수백 개 파일 이름 일괄 변경 — 날짜·거래처 규칙
  • 오래된 파일 자동 백업·압축
  • 흩어진 문서를 한 폴더로 취합 후 목록화
    • 프로그램 · 일과동선의 자동화
  • 아침 업무 세트 — 엑셀·메일·브라우저 한 번에 실행
  • 메일 작성 창 자동 호출 — 수신자·제목 채워서
  • 정해진 시간에 작업 실행 — 스케줄 등록
  • 프린터·네트워크 드라이브 연결 상태 점검
    • 팀 공용 도구도구의 자동화
  • 버튼 하나로 백업되는 GUI 프로그램 제작
  • 폴더 용량·파일 현황 리포트 자동 생성
  • 엑셀 시트 구조를 뽑아 AI 싱크용 텍스트 생성
  • 프로젝트 표준 폴더 트리 자동 생성
    • 시연 1폴더 정리 자동화 — 생성된 명령을 실행 전에 읽고 검증하는 습관까지가 시연 범위
    정리

    윈도우에 말을 걸 수 있게 됐다 — 운영체제가 첫 번째 자동화 대상이다.

    엑셀 — 함수 · VBA · 파워쿼리로 자동화할 수 있는 것

    .bas · .xlsx
    전제는 하나 — 구조 싱크. 표 3줄 복붙이든 구조 추출이든, AI가 내 시트 모양을 알아야 코드가 맞는다.
    함수 — 셀에서 바로
  • 다른 시트 값 자동 매칭 — 코드·이름으로 찾아오기
  • 조건별 합계·건수 집계 — 지점·월·품목 기준
  • 붙은 텍스트 분리·정리 — 이름/코드/날짜 추출
  • 오류값·빈칸 일괄 정돈
    • VBA — 반복 작업 매크로
  • 지점·월별 시트 자동 분리·취합
  • 서식·인쇄 설정 일괄 적용 — 문서 표준화
  • 전체 시트를 PDF로 일괄 저장
  • 매일 하는 복붙 루틴을 버튼 하나로
    • 파워쿼리 — 병합·갱신
  • 폴더 안 파일 수십 개 자동 병합
  • 매월 갱신 원본 — 새로고침 한 번으로 반영
  • 열 정리·형 변환 자동화 파이프라인
  • 두 표 대사 — 불일치 행만 추출
    • 시연 2표 3줄 복붙 → VBA 생성 → Alt+F11 실행 · 오류가 나면 오류문을 그대로 되물으면 스스로 고친다
    정리

    어려워서 미뤄둔 VBA·파워쿼리 — LLM이 있으면 도전 비용이 사라진다.

    PART 3 · 영역 4

    브라우저는 프로그램이다 — HTML 한 파일로 만드는 도구들

    .html · .css · .js
    설치 없이, 보안망 안에서 도는 업무 도구 — 파일 저장 → 더블클릭이 배포의 전부다.

    원리 — 한 파일 안의 세 언어

    html — 뼈대화면의 구조 — 제목, 표, 입력창, 버튼
    css — 모양색·배치·서체 — 회사 서식 재현까지 가능
    js — 기능동작 담당 — 파이썬만큼 방대한 라이브러리 생태계. 어떤 라이브러리를 쓰느냐가 도구의 성격을 정한다
    node.js — 브라우저 밖 실행내 컴퓨터에서 js를 직접 구동 — js가 파일탐색·변환 자동화 언어가 된다

    사례 — HTML 한 파일로 만든 업무 도구

  • 문서편집기 — 워드 없이 작성·인쇄, 양식 내장
  • 업무 계산기·시뮬레이터 — 단가·수수료·재고 규칙을 화면으로
  • 파일 변환기 — CSV↔엑셀, 이미지 형식 변환, 텍스트 정리
  • 체크리스트·점검표 앱 — 현장 점검을 태블릿으로
  • 견적서·양식 생성기 — 입력하면 인쇄용 문서 완성
  • 현황 대시보드 — 재고·실적 데이터를 그래프 화면으로
  • 엑셀·PPT 파일 생성기 — html이 오피스 문서를 만들어 내려준다
  • 교육·발표 자료 — 지금 보고 있는 이 강의안이 단일 html 파일
    • 정리

    브라우저 콘솔(F12) — 브라우저 자체를 제어한다

    시연 순서 — 준비물 없음, 개발자 도구는 모든 PC에 있다
    1아무 웹페이지에서 F12 를 누른다
    2Console 탭을 연다
    3LLM이 만들어 준 명령을 붙여넣는다
    4Enter — 화면이 바뀐다
    여기서도 구조는 같다 — 요청은 말로, 실행은 붙여넣기로.
    브라우저가 '보는 창'에서 '제어하는 프로그램'으로 바뀐다.

    사례 — 콘솔로 자동화할 수 있는 것

  • 표·목록 통째 추출 — 화면의 데이터를 한 번에 복사
  • 제목·링크 일괄 수집 — 조사 업무의 수작업 제거
  • 화면 정리 후 인쇄 — 배너·메뉴 숨기고 본문만
  • 반복 클릭 자동화 — '더보기' 끝까지 자동 전개
  • 반복 입력 자동화 — 같은 값 채우기를 명령으로

    • 중단 지점

  • 사내 시스템 적용 전 — 보안 정책 확인이 먼저, 오늘은 공개 페이지로만 · 실패 시 결과 화면으로 대체 설명

    밖과 연결되면 능력이 커진다 — API · MCP · RAG · 데이터 형식

    LLM
    연결 수만큼
    할 수 있는 일이 는다

    API — 외부 기능 호출

    다른 프로그램의 기능을 코드로 빌려 쓴다

    사례 — 환율·날씨·시세를 매일 아침 내 문서로 · 번역·지도·이미지 생성 연결

    MCP — 표준 확장 슬롯

    도구를 꽂는 연결 규격, 하네스 시대의 핵심

    사례 — 노션·구글드라이브를 LLM에 직접 연결 · 사내 시스템 연동 설계(AI팀 영역)

    RAG — 문서 읽기

    내 문서를 검색해 읽고 근거로 답한다

    사례 — 사규·매뉴얼 질의응답 · 계약서 뭉치에서 조건 찾아 비교

    데이터 형식 — RSS·XML·JSON·ODS

    프로그램끼리 데이터를 주고받는 그릇

    사례 — 뉴스 RSS 아침 브리핑 · 공공데이터(XML·JSON) 받아 보고서로
    공통점 네 가지 모두 LLM 혼자서는 못 보는 바깥을 보게 해 준다 — 3장의 도구 목록이 여기서 완성된다.
    연결

    연결이 곧 에이전트의 확장이다 — 형식(JSON·XML)은 읽을 줄만 알아도 연동이 보인다.

    확장자 지도 — 이게 보이면 시야가 넓어진다

    실행 환경언어 · 기술파일 확장자대표 업무대표 자동화 사례
    윈도우PowerShell · CMD (bash)운영체제에 직접 명령.ps1 · .bat파일·프로그램 제어, 업무 동선 자동화폴더 자동 정리 · 아침 업무 세트 · 백업 GUI
    엑셀함수 · VBA · 파워쿼리AI 싱크(구조 전달)가 핵심.bas · .xls · .xlsx표 계산, 반복 작업 매크로, 파일 병합시트 취합 매크로 · 파일 병합 · 표 대사
    파이썬파이썬 코드에이전트의 몸통.py데이터 분석, 문서 작업, API 호출엑셀 100개 취합 · PPT 자동 생성 · API 수집
    브라우저html · css · js설치 없는 실행 환경.html · .js · .svg · .json업무 도구, 문서, 시각화, 대시보드업무 계산기 · 파일 변환기 · 현황 대시보드
    교차 생성 파이썬(.py)과 브라우저(js)로 엑셀 파일(.xlsx)을 만들 수 있다 — 환경은 나뉘어도 산출물은 넘나든다. 만들어보고 열어보는 것이 훈련이다.

    사무직 PC 사용자의 LLM 활용 폭은 확장자 이해가 결정한다 — 한 주에 하나씩 만들어 볼 것.

    PART 4 · 적용

    직무가 달라도 구조는 같다 — 입력 · 영역 · 산출물

    시작점은 언제나 내 데이터 — 입력을 정의할 수 있으면 도구는 따라온다.
    직무입력쓰는 영역산출물자동화되는 장면
    마케팅캠페인 데이터, 채널별 리포트파이썬 · 엑셀 함수성과 리포트 자동 생성주간 보고 시간 회수채널 리포트 3개가 매주 자동으로 하나의 추이표가 된다
    영업실적 시트, 고객 목록엑셀 VBA · 함수취합·브리핑 시트지점별 취합을 매크로 하나로지점 시트 12개 취합이 버튼 한 번으로 끝난다
    재무정산 원장, 월마감 자료파워쿼리 · 파이썬집계와 차이 분석수작업 대사를 코드로 검증두 원장의 금액 불일치 행만 자동으로 추려진다
    SCM발주·재고·납기 데이터파이썬 · HTML 도구재고 리포트 · 예외 대시보드이상치를 먼저 보여주는 화면안전재고 미달 품목이 화면에 먼저 경고로 뜬다
    판정
