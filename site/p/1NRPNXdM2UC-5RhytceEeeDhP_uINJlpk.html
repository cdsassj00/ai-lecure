HOW IT WORKS

밖에서 묻고,
안에서 실행한다

1주차의 에이전트는 AI가 직접 도구를 쥡니다. 2주차는 사람이 도구를 쥐고 AI에게 사용법을 묻는 방식입니다. 회사 보안 정책과 충돌하지 않고, 오늘 당장 할 수 있습니다.

사람이 루프를 돈다. 이것이 간접 활용이다.
안전장치가 기본으로 들어 있다　중간에 사람이 반드시 한 번 눈으로 봅니다. 실제 데이터는 나가지 않고, 구조와 질문만 나갑니다.

에이전트 뒤에는
파이썬이 있다

AI가 “엑셀을 분석했습니다”라고 말할 때, 화면 뒤에서는 표를 읽는 코드·숫자를 더하는 코드·그래프를 저장하는 코드가 돌아갑니다. 그 언어가 파이썬입니다.

이 사실이 중요한 이유는 AI 대화창은 닫히지만 코드는 남는다는 점 때문입니다. 한 번 받아 둔 .py 파일은 내 컴퓨터에서 내일도, 다음 달에도 똑같이 돌아갑니다.

폐쇄망에서 특히 강력한 이유

망 밖 (인터넷)

업무를 설명하고, 자동화 아이디어를 받고, 가짜 데이터로 코드를 받아 시험합니다.

가져갈 것
.py 파일, 라이브러리 설치 파일, 사용 설명서.

망 안 (업무망)

반입 절차를 거친 코드를 실제 데이터에 연결해 매일 돌립니다.

나가지 않는 것
거래처명·단가·인명 등 실제 내용. 나가는 것은 구조뿐입니다.

이식 준비물 3가지　① 파이썬 설치 파일  ② 라이브러리 오프라인 설치 파일  ③ 사내 반입 승인 절차 확인
AI에게 물어서 얻어야 할 것은 답변이 아니라
반복해서 쓸 수 있는 도구입니다.

세 갈래의 길이 있다

상황추천이유
엑셀 파일 한 개 안에서 끝나는 계산함수설치도 저장도 필요 없고 결과가 즉시 보임
같은 엑셀 안에서 시트 여러 개를 매달 반복VBA엑셀에 이미 들어 있어 추가 설치가 없음
폴더의 파일 수십 개를 한꺼번에파이썬파일·형식·외부 시스템을 넘나들 수 있음
매일 아침 사람 없이 저절로 실행파이썬 + 윈도우작업 스케줄러가 .py를 대신 눌러 줌

무엇을 쓸지 모르겠다면 그 질문 자체를 AI에게 하십시오. “이 업무는 함수·VBA·파이썬 중 무엇이 적합합니까? 이유와 함께.”

EXCEL SYNC ①

파일을 올리지 말고
세 줄만 보여 준다

엑셀 자동화를 물을 때 파일 전체가 필요하지 않습니다. 컬럼 이름 한 줄 + 데이터 두 줄이면 AI는 표의 구조를 정확히 파악합니다.

1행 컬럼명 + 2행·3행 데이터 = 구조 설명 완료. 나머지 5,000행은 같은 형식의 반복일 뿐이다.
왜 세 줄로 충분한가　① 컬럼 이름이 각 열의 의미를 알려 준다  ② 데이터 두 줄이 형식(날짜·숫자·문자)과 쉼표·단위를 알려 준다  ③ 나머지는 코드에 영향을 주지 않는다
보안 측면에서 더 중요한 이유
실제 거래처명·단가·인명이 담긴 파일을 통째로 올리면 정보 유출입니다. 세 줄 싱크는 구조만 보내고 내용은 보내지 않는 방법입니다. 그 두 줄마저 가짜 값으로 바꾸면 더 안전합니다. 품번은 ABC-0001, 거래처는 가나다상사로 충분합니다.
실습 방법　엑셀에서 1~3행을 드래그해 Ctrl+C 하고, 대화창에 Ctrl+V 하면 탭으로 구분된 표가 그대로 붙습니다. 별도 변환이 필요 없습니다.

일자 라인 품번 생산수량 불량수량 담당 2026-08-03 A라인 HM-1042 1,200 14 김생산 2026-08-03 B라인 HM-2210 860 3 이설비
붙여넣은 뒤 이렇게 묻습니다
“위 형식의 표가 약 5,000행 있습니다. 1행이 컬럼명이고 시트 이름은 생산실적입니다.
① 라인별·월별 불량률(불량수량÷생산수량)을 구하고 ② 불량률이 2%를 넘는 건만 따로 표시하고 싶습니다.
엑셀 함수, VBA, 파이썬 세 가지 방법을 각각 알려 주고, 제 상황에는 어느 쪽을 권하는지 이유도 알려 주세요. 저는 초보자입니다.”

세 갈래로 돌아오는 답

① 함수

SUMIFS · XLOOKUP · 조건부 서식

지금 이 파일에서 바로 결과를 봅니다. 설치도 저장도 필요 없습니다.

② VBA

매크로 코드 + 실행 방법

매달 같은 작업을 버튼 하나로. 엑셀 안에서 끝납니다.

③ 파이썬

.py 코드 + pip 설치 명령

파일이 여러 개로 늘거나 자동 실행이 필요해지면 이쪽입니다.
✓요청에 반드시 넣을 것 : 행 수 · 시트 이름 · 컬럼명 위치 · 내 수준. 이 넷이 빠지면 돌아가지 않는 코드가 옵니다.

답 ② VBA
먼저 개발 도구를 켠다

VBA는 엑셀 안에 이미 들어 있는 자동화 언어입니다. 문법을 배우지 않아도, 붙여넣는 자리만 알면 됩니다. 그 자리로 가려면 리본에 ‘개발 도구’ 탭을 먼저 켜야 합니다.

엑셀 기본 설정에서는 개발 도구 탭이 숨겨져 있다. 한 번만 켜 두면 계속 남는다.

한 번만 하면 되는 준비

1엑셀 → 파일 → 옵션 → 리본 사용자 지정
2오른쪽 ‘기본 탭’ 목록에서 개발 도구 체크 → 확인
3리본에 생긴 개발 도구 탭 → Visual Basic (또는 Alt+F11)

저장할 때
확장자가 갈린다

잘 만든 매크로가 사라지는 가장 흔한 이유는 실행 실패가 아니라 저장 형식을 잘못 고른 것입니다.

.xlsx　일반 엑셀 파일 — 매크로를 담지 못합니다. 이대로 저장하면 코드가 통째로 날아갑니다.
.xlsm　매크로 사용 통합 문서 — VBA를 쓰면 반드시 이것으로 저장합니다.
.bas　VBA 코드만 따로 뽑아 낸 파일 — 동료에게 코드만 전달하거나 백업할 때.
.xlsb　이진 형식 — 매크로 저장 가능. 파일이 매우 클 때 속도가 빠릅니다.

동료에게 넘길 때

받는 사람의 엑셀에서 보안 경고 — 매크로를 사용할 수 없도록 설정했습니다라는 노란 띠가 뜹니다. 콘텐츠 사용을 눌러야 실행됩니다. 인터넷이나 메일로 받은 파일은 속성 → 차단 해제가 추가로 필요할 수 있습니다.

VBA를 AI에게 요청하는 문장
“엑셀 VBA로 만들어 주세요. 시트 이름은 생산실적, 1행이 컬럼명이고 컬럼은 일자·라인·품번·생산수량·불량수량·담당입니다. 라인별 불량률을 계산해 집계 시트에 정리하고, 불량률 2% 초과 행은 빨간색으로 칠해 주세요. 초보자용으로 한글 주석을 달고, 실행 방법도 순서대로 알려 주세요.”
VBA를 쓰기 좋은 경우　동료 PC에 파이썬을 설치할 수 없을 때, 결과를 반드시 엑셀 안에서 보여 줘야 할 때, 버튼 하나로 누구나 쓰게 만들고 싶을 때.

대시보드는
네 층으로 쌓는다

보기 좋은 화면부터 만들면 반드시 무너집니다. 아래에서부터 쌓아야 매달 자동으로 갱신되는 대시보드가 됩니다.

매달 반복되는 대시보드의 조건
새 데이터를 1층에 덮어쓰기만 하면 2·3·4층이 저절로 갱신되어야 합니다. 그렇지 않다면 그것은 대시보드가 아니라 매달 다시 만드는 보고서입니다.

가장 큰 시간 절감은 화려한 4층이 아니라, 아무도 알아주지 않는 2층 정리를 자동화할 때 나옵니다. 그리고 2층이야말로 파이썬이 가장 잘하는 일입니다.

내려받는다
