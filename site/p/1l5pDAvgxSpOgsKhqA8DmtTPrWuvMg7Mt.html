EGIS — 에너지·안전 통합 진단 AI Agent 계획서
한국환경공단 충청권환경본부 화학시설검사부  정주영 · 정윤진  /  기후에너지환경부 화학물질안전원  조명란
2026. 7. 31.

1. 추진 배경

  • 유해화학물질 취급시설 검사·진단 건마다 제출자료 검토, 측정 데이터 정리, 안전 판정 및 결과서 작성이 수작업으로 반복된다.
  • 현장에서 확보한 측정 데이터에 에너지 손실 정보가 포함되어 있지만, 현재는 안전 판정에 활용하는 데 그친다.

2. 추진 내용

  • 개발 내용: 유해화학물질 취급시설의 안전검사·진단과 에너지 손실 분석을 결합하여, 현장 측정 데이터 분석부터 「에너지·안전 통합 진단 결과서」 초안 작성까지 지원하는 AI Agent(EGIS)를 개발한다.
  • 해결방안: 제출자료와 현장 측정 데이터를 통합 분석하여 '안전 판정·법령 근거·에너지 절감액·지원사업 연계방안'이 담긴 「에너지·안전 통합 진단 결과서」 초안을 생성하고, 검사원의 검토·확정을 거쳐 사업장에 제공한다.
  • 기대 효과: ① 검사원의 서류 작성 업무가 검토·확정 중심으로 간소화된다. ② 안전 판정에만 쓰이던 측정 데이터에서 에너지 손실·예상 절감액 분석이 새로 산출되어, 법령 근거가 명시된 결과서로 사업장에 제공된다.

3. 주요 기능과 업무 흐름

3.1 핵심 기능

  • 검사·진단 자료 업로드 / 자료 자동 분류 / 설비 목록 확정 / 측정값 입력
  • 위험도 판정 · 에너지 손실 산출 / 결과서 초안 생성
  • (추후 검토) P&ID에서 설비 목록 추출 후 목록 대조

3.2 업무 흐름

  1. 사업장 제출자료 업로드
  2. 문서 자동 분류 → 설비 후보 작성 → 검사원 검토·확정 (승인 ①)
  3. 사업장 설비 측정 → 입력(EGIS) → 위험도 판정 · 에너지 손실 산출
  4. 결과서 초안 생성 → 검사원 검토·수정 후 확정 (승인 ②) → 사업장 제공

3.3 기능별 입력·출력 예시

기능입력출력 형식출력 예시
문서 분류 검사자료 업로드 문서 유형(JSON) 설비 리스트·P&ID → 설비현황 / 성적서·MSDS → 판정자료 / 사업장 개요 → 사업장정보 / 인증서·건축도면 → 참고 / 애매하면 미분류(검사원 판단)
위험도 판정 · 에너지 손실 산출 측정 데이터 판정 결과(JSON) 배관 P-01 두께: 적합, 근거 "화관법 시행규칙 별표5 / API 574"
결과서 초안 생성 판정 결과 + 근거 법령 원문 결과서 문장(자연어) 설비 소견: "…KEC 기준 1MΩ 미달로 절연 열화가 의심됨(참고: …)"

4. 시스템 구성

4.1 기술 스택

  • 형태: 웹앱(로컬 실행) — 업로드·검토 화면 중심
  • 언어/백엔드: Python · FastAPI · Pydantic
  • LLM: 로컬 LLM(모델 테스트 후 선정)
  • 데이터/RAG: 측정 데이터(입력) / 법령·업무매뉴얼 등 판정 근거(내부 DB 조회) — SQLite · SQLAlchemy
  • 프론트: FastAPI가 서빙하는 최소 HTML(Tailwind) 얇은 UI
  • 실행: 로컬

4.2 화면 · 데이터 · 외부 연동

항목내용
화면업로드(분류 결과·미분류 건수) / 설비 확정(설비 목록) / 측정 데이터 입력 / 판정·결과서 검토(초안)
데이터 모델설비 13종 · 측정 기록 3종 · 판정 기준 · 판정 결과 · 문서(유형 5종) · 결과서 등 8종
저장 데이터사업장 기본정보, 설비목록, 측정값, 측정결과 등 — 로컬 SQLite. 개인정보는 수집·저장하지 않으며, 개발·데모는 가상 사업장 샘플 데이터만 사용
외부 연동없음(로컬 구동) — 외부 API·크리덴셜 불필요. 입력 = 제출 파일(엑셀·CSV·텍스트 PDF·hwpx). 로그인·개인정보 없음

5. 신뢰성 · 안전 설계

5.1 AI와 검사원의 역할 분담

  • AI가 하는 일: 제출자료 자동 분류, 설비 후보 추출, 판정 결과 기반 결과서 초안 작성
  • 검사원이 하는 일: 현장 측정·측정값 입력, 설비 목록 확정, 진단 결과서 확정 — 모든 확정은 검사원의 몫

5.2 자동화 범위와 사람 승인

  • 자동: 파일 분류 → 설비 후보 추출 → 위험도 판정·에너지 손실 산출 → 결과서 초안 생성까지
  • 승인 2곳: ① 설비 목록 확정 화면(후보 검토·수정 후 저장) ② 진단 결과서 확정(초안 검토 후 승인)
  • 중단 조건: 자료에서 값을 읽어내지 못하면 추측하지 않고 "확인 필요"로 표시해 검사원이 직접 입력

6. 성공 기준

  • ① 판정 문장에 근거 출처를 100% 인용  ② LLM 출력이 정해진 형식을 준수  ③ 현행 수작업 시간 대비 단축 + 에너지 분석 신규 산출
  • 시나리오 2개(정상 실행 · 예외 처리) 데모 재현
