KCI 등재 등급별 학술지 영향력 분석 보고서

📌 요약 (Executive Summary)

본 보고서는 한국연구재단(NRF) KCI 데이터를 활용하여 학술지의 등재 등급(우수등재, 등재, 등재후보)에 따른 영향력 지수(IF)의 차이를 정량적으로 분석하였다. 분석 결과, 등급이 높을수록 영향력 지수가 유의미하게 높게 나타나 현행 등급 체계의 변별력이 확보됨을 확인하였다.

1. 개요

  • 분석 목적: KCI 등재 제도 등급별(우수등재/등재/등재후보) 학술지의 실제 학술적 영향력(인용지수) 비교 분석
  • 분석 대상: 2025년 기준 KCI 학술지 정보 및 인용지수 정보
  • 분석 지표: KCI 영향력 지수(2년) 평균값 (Impact Factor)

2. 데이터 처리 및 분석 방법

  • 데이터 결합(Data Joining): 학술지 정보와 인용지수 정보를 국제표준연속간행물번호(ISSN) 기준으로 결합
  • 전처리 수행:
    • ISSN 내 하이픈(-) 및 공백 제거를 통한 매칭률 향상
    • 중복 데이터 제거(Deduplication)를 통한 데이터 신뢰도 확보
    • 웹오브사이언스(WoS) 지수가 아닌 순수 'KCI 영향력 지수' 추출

3. 분석 결과

총 2790건의 유효 데이터를 바탕으로 등급별 평균 영향력 지수를 산출한 결과는 다음과 같다.

3-1. 등급별 평균 IF 현황표

등재 등급 평균 IF(2년) 학술지 수
우수등재 1.219 66
등재 0.834 2518
등재후보 0.431 121

3-2. 등급별 영향력 비교 시각화

4. 결론 및 시사점

  • 등급 간 뚜렷한 계단식 격차 확인:
    '우수등재(1.219) > 등재(0.834) > 등재후보(0.431)' 순으로 평균 인용지수가 뚜렷한 하락세를 보임.
  • 우수등재 학술지의 차별성:
    우수등재 학술지는 등재후보 학술지 대비 약 2.8배, 일반 등재지 대비 약 1.5배 높은 영향력을 보여, 최상위 등급으로서의 위상을 정량적으로 입증함.
  • 제도적 타당성 확보:
    현재 운영 중인 KCI 등재 평가 및 등급 부여 시스템이 학술지의 실제 영향력을 적절히 반영하고 있음을 시사함.

5. 향후 계획

  • 지속적인 모니터링: 매년 인용지수 변동 추이를 추적하여 등급 체계의 안정성 점검
  • 분야별 세부 분석: 인문/사회/자연과학 등 학문 분야별 특성을 고려한 세분화된 영향력 분석 추가 수행 필요
  • 평가 지표 고도화: 단순 인용 수치 외 중심성 지수, 즉시성 지수 등을 포함한 다각적 분석 모델 개발 검토
