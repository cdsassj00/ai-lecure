API는 "남이 만든 함수를 부르는 창문" — 세 줄이면 끝나는 개념

문서에 엔드포인트·메서드·페이로드라 쓰여도 겁먹지 않는다. 주소·동사·편지 세 단어로 바꿔 읽는다.

01 · THREE WORDS엔드포인트·메서드·페이로드
API 세 단어의 인문학적 번역

기술 용어를 일상어로 바꾸면 진입이 쉬워진다. API는 편지 한 통을 주소에 보내고 답장을 받는 일이다. 무엇 하나 새로운 개념이 없다.

응답 status 200잘 받았다는 답
응답 status 4xx반송 사유
KEY TAKEAWAY
API는 편지 왕래다

내용이 파이썬 딕셔너리·JSON일 뿐, 행위 구조는 같다.

01 · KEYAPI 키 관리의 3원칙
키가 유출되면 누구든 당신 계정으로 호출한다

API 키는 당신의 전자서명 + 결제카드다. 유출 시 요금이 붙고, 호출 한도가 소진되고, 서비스가 멈춘다. 세 가지만 지키면 99% 안전하다.

03 · RETRY실패·재시도 패턴
네트워크·서버는 일시 장애가 일상

API 호출 중 5~10%는 일시적 실패가 난다. 그렇다고 바로 에러 처리하면 스크립트가 자주 멈춘다. 지수 백오프로 재시도하면 대부분 자동 복구.

# 지수 백오프 재시도 import time def call_with_retry(fn, max_tries=5): for i in range(max_tries): try: return fn() except Exception as e: wait = 2 ** i # 1,2,4,8,16초 print(f"재시도 {i+1} · {wait}s · {e}") time.sleep(wait) raise RuntimeError("5회 실패")

UNIT 03 · MCP 개념 · LECTURE 08-B-1

MCP는 "에이전트가 도구를 꽂는 표준 콘센트"

API는 "각자 다른 소켓", MCP는 "모든 에이전트가 알아듣는 한 규격". 이 차이가 생태계를 바꾼다.

01 · WHY MCPAPI와의 차이
"우리 에이전트만의 도구"가 아니라 "표준 도구"

기존에는 Gmail·Slack·Notion 각각을 호출하려면 에이전트마다 개별 코드를 작성했다. MCP(Model Context Protocol)는 도구 쪽에서 한 번 MCP 서버를 만들면, 모든 MCP 지원 에이전트(Claude·Cursor·Antigravity 등)가 동일하게 사용 가능하게 한다.

02 · STRUCTUREMCP의 3계층
Host · Client · Server 세 역할
ROLE예시
HostClaude Desktop·Cursor
ClientHost 내 MCP 연결부
Server실제 도구 제공자

에이전트(Host)가 Client를 통해 여러 MCP 서버에 동시 연결. 각 Server는 tools·resources·prompts 세 가지를 노출.

# MCP 서버의 도구 노출 예 from mcp.server import Server app = Server("my-tools") @app.tool() async def search_민원(keyword: str) -> list: """부서 민원 DB에서 키워드 검색""" return db.query(keyword) @app.tool() async def draft_회신(민원id: int) -> str: """민원 ID로 회신 초안 생성""" return make_reply(민원id)
RESULT
Claude Desktop이 "search_민원" 함수를 그대로 호출 가능

설정 파일 한 줄로 연결. 에이전트 쪽 코드 변경 없음.

콘센트가 표준이 되자 가전이 폭발한 역사와 같다

# AI Architecture Canvas · 1p ## 01 · TRIGGER 트리거 매일 오전 9시 + 민원 폴더 신규 파일 ## 02 · MATERIALS 재료 - ./민원/*.pdf (신규) - 법령 API (선택적) - 과거 민원 RAG 인덱스 ## 05 · OUTPUT 산출물 ←먼저 정의 - ./결과/{일자}_분류.xlsx - 담당자 Slack 알림 - HWP 응대안 초안 ## 03 · PROCESS 처리 PyMuPDF로 텍스트 추출 → AI_CLASSIFY로 부서 지정 → RAG로 유사 사례 3건 → HWP 응대안 초안 생성 ## 04 · SYSTEM PROMPT "공공기관 민원 담당자처럼 답한다. 근거 조문·과거 사례를 반드시 명시. 개인정보는 마스킹." ## 06 · DEPLOY - 부서 PC · Windows 스케줄러 - 로그는 ./logs/로 - 월 1회 정답률 측정
