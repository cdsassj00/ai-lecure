Part 02 · Pre-Course배경 및 필요성생성형 AI 기업의 도래와 평가의 한계

Core Principle

지식이 아닌 수행 능력을 측정함. 실제 업무 시나리오에서 AI로 문제를 해결하는 과정과 결과를 LLM이 자동 채점하여 즉시 리포트를 생성함.

패러다임의 전환

생성형 AI는 더 이상 단순 도구가 아니라 기업의 업무 방식을 재정의하는 운영체제로 진화 중임. 삼성SDS · SK텔레콤 · 카카오 등 선도 기업이 'AI 네이티브 기업' 전환을 선언하고 전사 도입을 가속화함. Tool로서의 AI는 핵심 운영 기반으로 격상되었으며, 경쟁 우위의 핵심이 된 활용 역량을 측정할 새로운 방식이 필요함.

현행 평가의 한계

  • 단편적 지식 측정 — 단순 설문은 실무 해결력을 대변하지 못함
  • 수료 중심의 평가 — 강의 이수가 실제 업무 활용 능력을 보장하지 않음
  • 주관적 평가 — 편향이 발생하고 대규모 인원 평가 시 시간과 비용이 과다함
  • 현장 적용력을 확인할 방법이 사실상 부재함

우리의 해답 · Performance-Based Evaluation

  • 실무 시나리오 기반 진단 — 실제 업무 환경과 동일한 조건에서 측정함
  • LLM-as-a-Judge 자동 채점 — 빠르고 객관적인 피드백 제공
  • 즉시 PDF 리포트 + HR 대시보드 자동 업데이트

Part 02 · Framework4대 핵심 역량진단 프레임워크

AX 역량은 다음 네 가지 영역에서 측정됨. 각 영역은 객관식 자가진단(Part 1)과 프롬프트 실기(Part 2)에서 동시에 평가됨.

KPI 01 · ✏️

프롬프트 엔지니어링

LLM의 잠재력을 100% 끌어내는 지시 설계 능력

  • 페르소나 설정 — AI에게 역할을 부여해 전문적 답변 유도
  • 명확한 과제 정의 — 모호함 없이 원하는 바를 구체적으로 전달
  • 맥락 제공 — 배경정보·조건·제약을 함께 제공
  • 출력 형식 제어 — 구조·분량·스타일을 사전에 명시
KPI 02 · 📊

데이터 리터러시 & 분석

코딩 없이 자연어로 데이터를 탐색·가공·시각화하여 인사이트 도출

  • 데이터 전처리 지시 — 결측치·이상치·인코딩을 자연어로 요청
  • 분석 논리 설계 — 가설 → 검증 → 해석의 흐름 설계
  • 시각화 도구 활용 — 차트 종류 선택과 시각화 요청
  • 결과 해석 능력 — 통계 수치를 비즈니스 언어로 변환
KPI 03 · 🛡️

AI 윤리 및 리스크 관리

기술적 한계와 법적·윤리적 위험을 인지하고 안전하게 통제하는 능력

  • 환각현상 탐지 — 근거 없는 정보 생성 탐지 및 검증
  • 정보 보안 준수 — PII·영업기밀·사내 데이터 보호 원칙
  • 저작권 리스크 — AI 생성 콘텐츠의 법적 범위 이해
  • 편향성 제거 — 프롬프트 설계로 편향된 결과 방지
KPI 04 · ⚙️

워크플로우 자동화 설계

복잡한 업무를 AI가 수행 가능한 단위로 쪼개고 연결하는 설계 능력

  • 작업 단계 분해 — 복잡한 업무를 작은 AI 실행 단위로 분해
  • 검증 절차 설계 — 각 단계 출력값의 품질 검증 로직 설계
  • 예외 처리 설계 — 에러·이상 상황에 대한 분기 처리
  • 루프 최적화 — 반복 실행 구조로 대량 처리 효율화
