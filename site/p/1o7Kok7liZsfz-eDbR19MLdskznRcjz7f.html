1. 제안의 범위와 결론

보건 그린 5개·블루 5개, 복지 그린 5개·블루 5개 등 총 20개 후보를 제안한다. 이 가운데 각 구획 2개씩 총 8개를 중간보고 논의안으로 제시한다. 8개 주제는 미확정이며, 현재 결과물은 주제 선정과 개발 착수를 위한 설계자료다. 최종 8세트 데이터·24과목 문제·정답·완성 매뉴얼을 개발한 상태는 아니다.

우선 조합은 일반건강검진, 건강증진 프로그램 운영, 치매 통계, 당뇨병 집계, 자활기업, 지역아동센터, 아동 통합사례관리, 통합돌봄 의뢰·회신이다. 통합돌봄은 착수회의 요청을 반영한 조건부 안이며 공식 지침·서식 확보와 업무 검토가 필요하다. 건강증진 프로그램도 참여 원자료가 없으므로 공개 서식 확보와 합성 실적 설계가 선행된다. 나머지 후보 역시 콘텐츠 원문 보강·교육용 가공·정답 검증을 거쳐야 납품 가능한 세트가 된다.

2. 자료에서 확인한 요구

  • 최종 규모: 보건 4세트와 복지 4세트, 각 분야 그린 2·블루 2, 세트당 콘텐츠·분석·자동화 3과목으로 24과목.
  • 수요조사 분석보고서(2026.9.10)는 60응답·50기관을 분석했다. 보고서 초안 48명(80.0%), 추이 분석 47명(78.3%), 반복업무 자동화 44명(73.3%), 오류 확인 40명(66.7%), 챗봇 18명(30.0%)이다. 이는 제공 보고서의 집계이며 이번 작업에서 원응답 재코딩은 수행하지 않았다.
  • 업무 대상의 서술 빈도는 자격 확인 9건, 민원 응대 8건, 건강증진·통합사례관리·통합돌봄 각각 5건, 치매 4건이다. 실적 취합 21건과 보고서 작성 19건은 주제가 아닌 수행 방식으로 적용했다. 복수 코딩 결과이므로 언급 수를 합쳐 응답자 수로 해석하지 않는다.
  • 표본의 90%가 지자체이며 기본 이하 활용 수준은 70%이다. 산하기관 전체를 대표하는 수요로 단정하지 않는다. 난이도를 낮추기보다 단계별 힌트·중간 산출물·강사용 피드백을 준비한다.
  • 활용가이드 v.3의 목적은 강사가 자신의 수업에 맞는 데이터를 고르는 참조서이다. 인증 운영 규격은 강사용 부록에 배치하고 본문은 데이터의 성격·실습 방법·결과 판독을 중심으로 작성한다.

3. 행정안전부 문제유형 적용

유형 코드는 행정안전부 지침의 과목별 30종 표를 참조한다. 동일 코드가 과목마다 다른 뜻이므로 반드시 과목과 함께 읽는다. 본 제안은 원문 유형을 업무에 맞게 조합한 안이며 확정된 문제지나 채점 규격이 아니다.

그린은 AI를 활용한 문서 대조·집계와 브라우저 안에서 실행되는 단일 도구를 중심으로 한다. 블루는 다중 자료·마스터 결합·정제 순서·예외 로그·반복 실행을 결합한다. Python 지도 역량은 강사 전제이며 학습자의 코드 문법 암기를 요구하지 않는다. 데이터에 적합하지 않은 예측모델이나 챗봇을 형식적으로 넣지 않는다.

문서 과목은 자료를 몇 개 열어 답을 찾는 수준을 넘도록 요약·분류·대조를 결합한다. 외부 근거자료 12개 이상과 ZIP 내부를 포함한 실질자료 12개 이상을 개발 검토 기준으로 두되, 사본·목차·장식 파일로 수량을 채우지 않는다. 현재 후보별로 그 수의 원문을 확보한 상태는 아니며 개발 단계의 보강 항목이다. 파일 목록 전체와 ZIP 내부 확인을 과제 안내에 명시한다.

수치 정답은 원본→가공→검증 코드의 계산 결과로 고정하고, 집계 단위·제외 규칙·반올림·허용오차를 기록한다. AI 초안의 오류와 가공 데이터의 오류는 강사용 이력에 남긴다. 현재 제안서에는 계산하지 않은 정답값을 적지 않았다.

6. 기개발 소재 대조와 제외 범위

인접 폴더의 3개 부처 정규 경로에서 그린·블루 × 실전·연습 문제지 180개, 등급을 포함한 세트 경로 60개를 확인했다. 부처별 주제는 실전 5개·연습 5개로 총 30개이며 양 등급에 반복 배치되어 있다. 문제지 본문에서 제목을 추출하고 과목별 첨부 파일명을 목록화했다. 이는 정규 경로 기준이며 보관본·배포 사본을 합산하지 않는다. 원문 첨부 전체의 의미 중복을 전수 판정한 것은 아니다.

제공 사업계획서에는 기보유 24세트, 로컬 종합보고서에는 주제 묶음 30세트가 표기되어 기준이 다르다. 최종 납품 목록이 확정되기 전에는 더 넓은 로컬 정규 경로를 보수적으로 대조 기준에 포함한다.

기존 소재군 실제 확인한 예 이번 처리
의료급여·요양급여·분만취약지 의료급여 대상자, 본인부담 계산, 요양급여 기준 우선안 제외
기관등록·의료기관 통계 진료정보교류 참여기관, 병원의원 수, 시설 등록 검증 HG03·HB03는 인접 예비안
암·마음투자 암 발생자수, 암 대시보드, 마음투자 제공인력 암·자살·정신건강 통계는 우선안 제외
감염병·검역·예방접종 백신, 인플루엔자, 엠폭스, CRE, HIV, 요양병원 감염관리 신규 후보에서 제외
식품·영양·의약품·의료기기 영양성분, 위생용품, 식품표시, 의약품허가 신규 후보에서 제외
일반 정책·규정 주요업무, 옴부즈만, 결산, 비영리법인 범용 보고서·규정 요약을 독립 주제로 채택하지 않음
추가 사용 이력 주의 확보현황 비고의 기초생활·장기요양·노인복지시설 파일럿 기록 기초생활·장기요양 데이터 재사용은 우선안 제외

같은 유형을 쓰는 것과 같은 소재를 재사용하는 것은 구분한다. 중복 최종 판정은 업무 대상·원문/데이터·수행 과정·산출물의 네 축으로 다시 검토한다. 주제명만 바꾸거나 같은 데이터를 다른 부처명으로 치환하는 방식은 채택하지 않는다.

7. 원자료 가용성과 개발 조건

확보현황 엑셀의 69항목은 확보 39항목과 제외·후속 항목을 함께 포함한다. 목록에 있다는 이유로 다운로드 완료로 간주하지 않는다. ZIP에는 (2) 사본과 utf8 변환본이 있으므로 실질자료 개수와 구분한다. 이번 작업은 원본 ZIP과 해제 파일을 보존했고 정리 목적 삭제는 수행하지 않았다.

일반건강검진·치매·자활·기관·아동센터 등 CSV는 파일을 열어 헤더와 행 수를 실측했다. 상세 경로·인코딩·SHA256은 검토근거 JSON에 기록했다. CSV 존재 확인은 이용조건·내용 정확성·최신성의 최종 검수를 대신하지 않는다. 외부 링크를 새로 조회하거나 미확보 자료를 수집하지 않았으므로 첨부된 연도·상태를 기준으로 제안했다.

합성 자료가 필요한 업무는 통계 집계를 개인 기록으로 역산하지 않는다. 공개 서식에서 필드 구조를 확인한 뒤 독립적인 교육용 사례를 생성하고 파일·문제지에 합성임을 표시한다. 교육용 처리 규칙과 실제 제도 기준을 구분하고 실제 행정 판단에 사용하는 도구로 제시하지 않는다.
