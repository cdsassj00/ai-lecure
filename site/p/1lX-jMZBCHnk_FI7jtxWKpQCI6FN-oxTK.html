결과를 확인하는 관점과 주의할 점
AI가 만든 결과는 원본 자료와 비교하며 확인하고, 외부로 나가는 행동은 사람이 결정합니다.
확인 1판정 기준교육 대상 판정 기준이 문장으로 적혀 있는지 봅니다.
확인 2수식수식이 모든 행에 적용되고 빈칸을 어떻게 처리하는지 봅니다.
확인 3개인정보필요한 열만 사용했고 외부 공유 파일에서 식별 정보를 뺐는지 봅니다.
확인 4합계부서별 인원을 더한 값이 전체 인원과 같은지 봅니다.
