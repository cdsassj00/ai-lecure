UNIT 01 · 파이썬 자동화 4종 · LECTURE 05-A

파일·엑셀·PDF·메일 — 공공 실무 반복의 80%는 이 네 가지에서 나온다

외부망에서 LLM과 함께 코드를 만들고, 내부망에 옮겨 실행한다. 이 듀얼 네트워크 운영이 어시스트 바이브 코딩의 기본 동선이다.

01 · FILE SYSTEMos · shutil · pathlib
폴더 스캔 → 조건 필터 → 이름 변경·이동의 3단 패턴

pathlib.Path.glob() 한 줄로 특정 확장자·날짜·키워드 파일을 수집한다. shutil.move / copy로 규칙별 분류, os.rename으로 파일명 표준화까지 세트로 묶는다.

# [실습예시] 민원 PDF 월별 자동 분류 from pathlib import Path import shutil, re src = Path("./민원접수") for f in src.glob("*.pdf"): m = re.search(r"(\d{4})-(\d{2})", f.name) if m: dst = src / f"{m[1]}-{m[2]}" dst.mkdir(exist_ok=True) shutil.move(f, dst / f.name)
KEY TAKEAWAY
"파일 찾기·정리" 수작업은 평균 주 90분을 잡아먹는다.

같은 규칙의 반복을 3회만 해도 자동화 ROI가 나온다. 한 번에 큰 시스템을 짜지 않고, 폴더 한 개의 규칙부터 시작한다.

02 · CODE SKELETONloop + template + save
실습예시 · 20줄로 끝나는 일괄 생성 스크립트
# 명단 30건을 읽어 공문 30개 생성 from pyhwpx import Hwp import csv from pathlib import Path TEMPLATE = "./공문_양식.hwp" OUTDIR = Path("./out") OUTDIR.mkdir(exist_ok=True) hwp = Hwp(visible=False) with open("명단.csv", encoding="utf-8") as f: for row in csv.DictReader(f): hwp.open(TEMPLATE) for k, v in row.items(): hwp.put_field_text(k, v) name = f"{row['부서']}_{row['이름']}.hwp" hwp.save_as(str(OUTDIR / name)) hwp.clear() hwp.quit()

핵심은 put_field_text(key, value) 한 줄이 명단의 한 컬럼을 양식 필드 하나에 꽂는다는 점. CSV 헤더와 HWP 누름틀 이름을 맞춰두면 row.items() 루프 한 줄로 전체 치환이 끝난다.

PITFALL
▸ clear() 누락 시 이전 내용이 다음 루프에 섞인다
open→save_as→clear 3단 리듬을 반드시 지킨다.
03 · HWP → PDF · LOG일괄 변환 + 실행 로그

# HWP → PDF 일괄 변환 + 로그 import time, csv from pathlib import Path log = [] for h in Path("./out").glob("*.hwp"): t0 = time.time() try: hwp.open(str(h)) hwp.save_as(str(h.with_suffix(".pdf"))) status = "OK" except Exception as e: status = str(e) log.append([h.name, status, round(time.time()-t0, 2)]) csv.writer(open("log.csv","w")).writerows(log)

완전 내부망 AI — Ollama + VBA로 엑셀에 =AI_ASK() 넣기

외부 API 호출 없이, 기관 PC 한 대 안에서 돌아가는 로컬 LLM. 엑셀 셀에서 함수처럼 부르는 다섯 가지 사용자 정의 함수(UDF)를 직접 짠다.

01 · WHAT IS OLLAMAlocalhost:11434 AI 서버
LLM을 내 PC에 한 번 설치하면, REST API처럼 호출된다

Ollama는 로컬에서 LLM을 실행·관리하는 런타임이다. 설치 후 ollama pull llama3.2 한 줄이면 모델이 로컬로 내려오고, http://localhost:11434/api/generate에 JSON을 POST하면 응답이 돌아온다. 완전 오프라인·외부 통신 없음이 보안의 핵심.

외부망 — 모델 다운로드 1회

Ollama 설치 파일·모델 파일(수 GB)을 외부망에서 받아 USB·보안 이관.

내부망 — 이후 완전 오프라인

일단 설치되면 외부 통신 없이 무제한 호출. 민감 데이터를 외부로 보낼 일이 사라진다.

# Ollama 설치 확인 (cmd 한 줄) ollama list # NAME SIZE MODIFIED # llama3.2:3b 2.0 GB 2 days ago # qwen2.5:7b 4.7 GB 5 days ago
KEY TAKEAWAY
"AI 함수"의 본질은 REST API 호출 래퍼다

VBA가 어려운 게 아니라 "localhost에 JSON 보내고 받기" 한 줄이 전부.

02 · FIVE FUNCTIONSUDF 다섯 개 시그니처
엑셀 셀에서 바로 쓰는 다섯 가지 사용자 정의 함수

[실습예시] 사용 모습
' 민원 제목 자동 분류 (A2:A500에 민원 원문) =AI_CLASSIFY(A2, "환경,교통,복지,세무,기타") ' 긴 민원 요약 15자 이내 =AI_SUMMARIZE(A2, 15) ' 영문 메일 한글 번역 =AI_TRANSLATE(B2, "ko")

수식이 끝난 셀을 아래로 드래그하면 500행 전체가 자동 처리. 엑셀에 익숙한 공직자가 코드 없이도 AI를 쓰게 하는 것이 목표다.
