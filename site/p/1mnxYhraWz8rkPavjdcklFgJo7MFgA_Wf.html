UNIT 01 · RAG 4단계 · LECTURE 07-A-1

RAG는 4단계뿐 — 넣기 · 쪼개기 · 찾기 · 답하기

검색-증강-생성이라는 번역어에 겁먹지 않는다. 네 단계를 한국어 동사로 바꾸면 고등학생도 이해할 수 있다.

01 · WHY RAG왜 LLM이 부족한가
LLM은 "세상 일반"을 알지만 "우리 부서"를 모른다

Claude·GPT는 인터넷 공개 지식으로 학습됐다. 당신 기관의 내부 규정, 작년 감사 결과, 이번 분기 보고서는 모른다. RAG는 답변 시점에 우리 문서를 옆에 놓고 참조하게 하는 기법이다.

02 · FOUR VERBS네 단계의 역할
STEP 01 · 넣기
문서를 시스템에 수집

PDF·HWP·DOCX → 텍스트 추출. PyMuPDF·pyhwpx·python-docx 활용.

STEP 02 · 쪼개기
긴 문서를 검색 단위로 분할

500자 ± 100 청크. 문단·섹션 경계 우선. 겹침(overlap) 50자 권장.

STEP 03 · 찾기
질문과 관련 청크 검색

키워드(BM25) 또는 의미(벡터) 기반. 상위 3~5개만 선정.

STEP 04 · 답하기
LLM이 청크 + 질문으로 답변

"아래 문서만 참고해서 답하라" 프롬프트. 출처 표기 강제.

SOURCE · 공공 AI 도입 지침
"출처 없는 답변은 공공 업무에서 사용하지 않는다."
— RAG의 존재 이유
03 · EXAMPLE처음부터 끝까지
[실습예시] 내 부서 내부 규정 Q&A
# 1. 넣기 — PDF 10건을 텍스트로 import fitz docs = [] for pdf in Path("./규정").glob("*.pdf"): d = fitz.open(pdf) txt = "\n".join(p.get_text() for p in d) docs.append({"src": pdf.name, "text": txt}) # 2. 쪼개기 — 500자 청크 chunks = [] for d in docs: for i in range(0, len(d["text"]), 450): chunks.append({ "src": d["src"], "text": d["text"][i:i+500] }) # 3. 찾기 — 키워드 기반 간단 검색 def search(q, k=3): scored = [(c, sum(w in c["text"] for w in q.split())) for c in chunks] return sorted(scored, key=lambda x: -x[1])[:k] # 4. 답하기 — Ollama 호출 def answer(q): hits = search(q) ctx = "\n\n".join(h[0]["text"] for h in hits) return ollama.chat(f"다음만 참고:\n{ctx}\n\n질문: {q}")

이 30줄이 RAG의 전부다. 70줄 안에 완전한 RAG를 짤 수 있다는 사실이 진입을 열어준다.

01 · SCALE TRUTH문서 규모의 현실
대부분의 공공 RAG는 "책 한 권 분량"을 다룬다

02 · KEYWORD FIRSTBM25 + 한국어 형태소
제일 간단한 검색이 가장 먼저 올 것

Python의 rank_bm25는 pip 한 줄 설치, 50줄 이내로 완성된다. 한국어는 형태소 분석 없이도 공백·조사 단순 분리만으로 70~85% 품질. 더 필요하면 kiwi·okt 같은 형태소 분석기를 얹는다.

# 30줄 한국어 RAG — BM25 + Ollama from rank_bm25 import BM25Okapi import re def tok(s): # 간단 한국어 토큰화 return re.findall(r"[가-힣]+|[a-zA-Z0-9]+", s) corpus = [tok(c["text"]) for c in chunks] bm = BM25Okapi(corpus) def search(q, k=5): scores = bm.get_scores(tok(q)) top = scores.argsort()[-k:][::-1] return [chunks[i] for i in top]

단일 HTML이 가장 빠르고 가장 이식성 높다

Remotion — 영상을 React 컴포넌트처럼 코드로 만든다

공공 홍보 영상·교육 자료·안내 영상을 매번 편집 툴로 만들 필요 없다. 데이터가 바뀌면 영상이 자동 갱신된다.

01 · CONCEPT영상 = 코드
타임라인 대신 타임 함수 — 프레임 번호로 위치 계산

Remotion은 React 기반 영상 렌더러. 각 프레임이 React 컴포넌트로 그려지고, useCurrentFrame()으로 현재 프레임 번호를 받아 위치·투명도·크기를 결정한다. 영상 편집이 아니라 함수 합성이다.

// MyVideo.jsx · 30초 영상 import {useCurrentFrame, interpolate} from 'remotion'; export const MyVideo = ({title, value}) => { const frame = useCurrentFrame(); const opacity = interpolate(frame, [0, 30], [0, 1]); return ( <div style={{opacity, fontSize: 80}}> {title}: {value.toLocaleString()}원 </div> ); };

데이터가 props로 들어간다 — 매번 렌더만

UNIT 04 · SVG 자동화 · LECTURE 07-D-2

SVG는 "텍스트로 그리는 그림" — 보고서 그래프가 코드가 된다

매달 PowerPoint로 그리던 조직도·플로우차트·통계 차트를 템플릿 한 번에 자동 생성한다.

01 · WHY SVG이미지 아닌 코드
SVG = XML = 텍스트 = Git 관리 가능

PNG·JPG는 픽셀 덩어리. SVG는 좌표·색·크기의 텍스트 기술이다. 에이전트가 직접 생성·수정 가능하고, 데이터가 바뀔 때마다 재렌더된다. 공공 보고서의 도식·차트에 가장 적합.

<!-- bar.svg — 5줄로 막대 차트 --> <svg viewBox="0 0 400 200"> <rect x="10" y="120" width="40" height="60" fill="#b8532a"/> <rect x="60" y="80" width="40" height="100" fill="#b8532a"/> <text x="200" y="20">월별 접수</text> </svg>
KEY TAKEAWAY
에이전트가 "데이터→SVG"를 작성하게 한다

매번 그리지 않는다. 함수 하나 만들고 호출만.

02 · PIPELINE데이터→SVG→PDF
파이썬 50줄로 끝나는 차트 생성 함수
# make_chart.py def bar_chart(data, title): svg_w, svg_h = 800, 400 bars = "" max_v = max(data.values()) for i, (k, v) in enumerate(data.items()): h = (v/max_v) * 300 x, y = 50 + i*80, 350 - h bars += (f'<rect x="{x}" y="{y}" ' f'width="60" height="{h}" ' f'fill="#b8532a"/>' f'<text x="{x+30}" y="375">' f'{k}</text>') return f'''<svg viewBox="0 0 {svg_w} {svg_h}"> <text x="400" y="30" text-anchor="middle" font-size="24">{title}</text> {bars} </svg>''' # 사용 svg = bar_chart({"1월":120, "2월":180}, "접수 현황") open("chart.svg", "w").write(svg)

생성된 SVG는 그대로 HTML·보고서·슬라이드에 삽입 가능. CairoSVG로 PNG·PDF로도 변환.
