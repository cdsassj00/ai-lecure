Cowork — 확인된 사실과 아직 단정하면 안 되는 부분

확인 수준이 높은 내용

  • 비개발자를 위한 일반 업무·파일 중심 에이전트
  • 사용자가 지정한 폴더를 읽고·편집하고·파일을 생성
  • 계획을 세우고 여러 작업을 큐에 넣어 처리
  • Cowork의 Dispatch가 필요하면 Claude Code 세션을 생성할 수 있음

표현을 조심해야 할 내용

  • “내 PC에 Linux 컨테이너를 반드시 띄운다”는 공식 기술 사양은 공개 문서에서 확인하기 어려움
  • WIRED 인터뷰에는 가상머신과 허가 폴더를 사용한다는 Anthropic 관계자 설명이 있음
  • 따라서 가상화 기반 격리라고는 설명할 수 있지만, OS 종류·호스트 방식은 버전별 공식 확인 필요
  • Cowork도 클라우드 세션·Code 세션으로 라우팅될 수 있어 “항상 로컬”이라고 단정하면 안 됨
대표님의 문장 교정 “Cowork는 Linux 샌드박스를 내 컴퓨터에 올린다” → “Cowork는 허가된 로컬 폴더와 격리된 실행 메커니즘을 사용하지만, 구체적인 VM/OS 구조는 공식 문서로 확인한 범위만 말한다.” A2·S1
