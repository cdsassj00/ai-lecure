HTML은
태그로 이루어진다

태그는 <여는 것> 내용 </닫는 것> 모양의 표식입니다. 이름만 알아보면 충분합니다.

태그하는 일업무 화면에서
<h1> ~ <h3>제목대시보드 카드 제목, 보고서 항목명
<p>문단설명 문장, 안내 문구
<table>표실적표, 접수 내역, 집기 집계
<input>입력창수량·날짜·검색어 입력
<select>선택 목록권역·센터·설비유형 필터
<button>버튼계산 실행, 내보내기, 저장
<div>묶음 상자카드·패널·영역 구분 (가장 많이 쓰임)
<canvas> <svg>그림판차트, 도면, 3D 화면이 그려지는 곳

실제 파일의 뼈대

<!doctype html> <html> <head> ← 제목·글꼴·CSS가 들어가는 머리 <body> ← 화면에 보이는 모든 것이 들어가는 몸통 <script> ← JS가 들어가는 자리 (보통 맨 아래) </html>
우리가 만든 파일을 열어 보면　머리에 <style>, 몸통에 화면, 맨 아래 <script> — 세 층이 한 파일 안에 순서대로 들어 있습니다. 그래서 파일 하나만 주고받으면 됩니다.

꾸미는 일이다

CSS 문장은 딱 두 부분입니다. 누구를 고를 것인가, 그리고 어떻게 바꿀 것인가.

자주 쓰는 선택자

.card　class="card" 인 것들 (여러 개)
#total　id="total" 인 것 하나

자주 쓰는 속성

color · background　글자색 · 배경색
padding · margin　안쪽 여백 · 바깥 여백

border-radius · box-shadow　둥근 모서리 · 그림자
실무에서 가장 많이 고치는 것　색과 여백, 그리고 글자 크기입니다. AI에게 “카드 배경을 더 밝게, 글자를 조금 키워 주세요”라고 말하면 CSS만 고쳐 돌려줍니다. 기능은 그대로 두고 보기만 바꾸는 요청입니다.

JS는 사건에
반응하는 일이다

자바스크립트가 하는 일은 결국 하나의 문장으로 요약됩니다. “어떤 일이 생기면 → 무엇을 계산해서 → 화면을 바꾼다.”

업무 프로그램에서 JS가 실제로 맡는 일

1데이터 읽기　엑셀·CSV 파일을 열거나 붙여넣은 표를 해석합니다.
2계산과 집계　합계·평균·비율·순위를 구합니다. 엑셀 함수가 하던 일입니다.
3그리기　차트·표·도넛·3D 화면을 화면에 그립니다.
4저장　localStorage에 이 PC에만 남기거나, CSV·PDF 파일로 내려받습니다.
✓중요한 성질 : JS는 그 사람의 브라우저 안에서만 돕니다. 데이터가 서버로 나가지 않습니다. 이것이 보안망 업무에서 결정적입니다.

길 ① 파일 업로드
가장 평범한 방법

화면에 파일 선택 버튼이나 끌어놓기 영역을 두고, JS가 그 파일을 읽어 표로 바꿉니다.

<input type="file" accept=".xlsx"> ← HTML : 파일 고르는 칸 <script src="xlsx.full.min.js"> ← 라이브러리 : SheetJS → JS가 파일을 읽어 → 표 → 차트로 그린다

두 가지 방식

라이브러리를 쓰는 방식

SheetJS(xlsx.js)를 불러오면 .xlsx든 .csv든 한 줄로 읽힙니다.

장점
가장 빠르고 확실합니다.

제약
라이브러리 파일이 필요합니다.

직접 만든 파서

수업에서 만든 대시보드 한 종류는 라이브러리 없이 브라우저 기본 기능만으로 xlsx를 풀었습니다.

원리
xlsx는 사실 ZIP으로 압축된 XML 묶음입니다. 브라우저의 압축 해제 기능(DecompressionStream)으로 풀고 XML을 읽습니다.

장점
파일 하나로 완전 오프라인 동작.

여기서 배운 큰 교훈
“라이브러리가 없으면 못 한다”가 아닙니다. AI에게 “외부 라이브러리 없이, 최신 엣지/크롬에서만 동작해도 되니 xlsx를 직접 파싱해 주세요”라고 조건을 주면, 그 조건에 맞는 코드를 만들어 냅니다. 제약을 먼저 말하는 것이 요청의 핵심입니다.

업로드가 막혔을 때의 신호 — 파일 선택 창이 안 뜨거나, 선택해도 아무 일이 없거나, 보안 프로그램이 경고를 띄웁니다. 그때는 미련 없이 길 ②로 갑니다.

길 ② 엑셀 복붙

엑셀에서 범위를 Ctrl+C 하고 화면에 Ctrl+V 하면 끝입니다. 업로드도, 서버도, 저장도 없습니다.

붙여넣기 창. 컬럼 수·행 수·용량이 실시간 표시되고, ‘대시보드 생성’을 누르면 KPI·차트·순위가 만들어진다.

원리는 아주 단순하다

1. 엑셀은 복사할 때 클립보드에 탭(Tab)으로 열을 나누고 줄바꿈으로 행을 나눈 글자를 넣습니다.
2. JS는 붙여넣기 사건에서 그 글자를 받아 줄바꿈과 탭으로 쪼갭니다.
3. 첫 줄을 컬럼명으로, 나머지를 데이터로 삼으면 표가 완성됩니다.
4. 그다음은 계산·차트·순위 — 평범한 JS입니다.
2주차의 ‘세 줄 싱크’와 같은 원리
AI에게 구조를 알려 줄 때 세 줄을 붙여넣었던 그 방식 그대로, 이번에는 내가 만든 프로그램에 전체 데이터를 붙여넣는 것입니다. 첫 행이 컬럼명이어야 한다는 규칙도 똑같습니다.

보안 담당자에게 설명할 때 — 파일이 업로드되지 않습니다. 클립보드 내용이 브라우저 안에서만 처리되고, 창을 닫으면 사라집니다.

길 ③ HTA
HTML을 프로그램처럼

HTA(HTML Application)는 확장자만 .html → .hta로 바꾼 파일입니다. 더블클릭하면 브라우저가 아니라 윈도우 프로그램으로 열리고, 브라우저가 막아 두었던 일들이 허용됩니다.

// HTA 안에서만 동작하는 코드 — 엑셀을 백그라운드로 열어 셀을 읽는다 var excel = new ActiveXObject("Excel.Application"); excel.Visible = false; var wb = excel.Workbooks.Open("C:\\data\\생산실적.xlsx"); var v = wb.Sheets(1).Cells(2, 4).Value; ← 2행 4열 값
언제 쓰는가　“매일 같은 경로의 엑셀을 열어 자동으로 집계해야 하는데, 파일 업로드는 막혀 있고 파이썬 설치도 안 된다” — 이런 상황에서 HTA가 유일한 답이 되는 경우가 있습니다.
3주차 강의요약13
3주차PART B데이터를 들이는 법11

HTA는
세 줄만 더 넣으면 된다

반드시 알아 둘 주의점

1윈도우 전용입니다. 맥·모바일에서는 열리지 않습니다.
2엑셀 조작은 엑셀이 설치된 PC에서만 됩니다. ActiveX가 엑셀 프로그램을 빌려 쓰는 방식이기 때문입니다.
3보안 정책에 걸릴 수 있습니다. HTA는 권한이 넓어 사내 백신이 차단하기도 합니다. 반드시 사전에 승인을 받으십시오.
4구형 엔진(IE 기반)으로 돕니다. 최신 문법과 최신 라이브러리는 안 될 수 있으니, HTA용은 기능을 단순하게 만듭니다.
실무 조합　평소에는 브라우저 + 복붙으로 쓰고, 매일 자동으로 돌려야 하는 것만 HTA로 따로 만듭니다. 화면 코드는 거의 그대로 재사용됩니다.

WHY IT WORKS

브라우저가
3D를 그리는 이유

브라우저에는 그래픽카드를 직접 쓰는 통로(WebGL)가 열려 있습니다. three.js와 Babylon.js는 그 통로를 쉽게 쓰게 해 주는 라이브러리입니다.

3D가 실제로 쓸모 있는 업무

공간 배치　사무실·창고·전시부스 레이아웃과 수용 인원 검토
설비 배치　장비 간 이격거리, 동선, 유지보수 공간 확인
제품 설명　고객에게 구조를 돌려 가며 보여 주기
교육·안전　비상 동선, 소화기·비상구 위치 점검
주의　3D는 그래픽카드가 없는 낡은 PC나 원격 접속 환경에서 느리거나 안 열릴 수 있습니다. 그래서 이 시뮬레이터도 평면도 모드를 기본값으로 두었습니다.
