AI 리터러시와 AI 도구 지도

AI의 현재 지형을 이해하고, ChatGPT·Claude·Gemini·Perplexity·NotebookLM 같은 도구를 목적에 맞게 구분해 쓰는 기초 모듈

강사가 전달할 핵심 메시지
·AI는 하나의 도구가 아니라 여러 기능을 가진 생태계다
·ChatGPT, Claude, Gemini, Perplexity, NotebookLM은 같은 AI처럼 보여도 강점이 다르다
·AI 활용 능력은 "질문을 잘하는 능력"을 넘어 "업무 흐름을 재설계하는 능력"이다
·강사는 지식을 전달하는 사람에서 AI와 함께 학습 경험을 설계하는 사람으로 바뀐다
대표 실습
1같은 질문을 여러 AI에 던져보기 — 답변 구조·구체성·최신성·출처 기준으로 비교
2AI 도구 선택 지도 만들기 — 업무 유형별 적합 도구 매핑
3AI 활용 수준 자가진단 — 질문 → 생성 → 자동화 → 재설계 4단계 중 내 위치 표시

프롬프트와 대화 설계

단순히 질문하는 수준을 넘어, 역할·맥락·자료·형식·검증 기준을 설계하여 원하는 결과물을 안정적으로 얻는 모듈

강사가 전달할 핵심 메시지
·프롬프트는 주문이 아니라 업무 지시서다
·좋은 프롬프트는 역할, 맥락, 목표, 자료, 출력 형식, 평가 기준을 포함한다
·결과가 마음에 들지 않을 때는 "다시 해줘"가 아니라, 어떤 기준으로 수정할지 알려줘야 한다
·강사는 프롬프트 예시보다 프롬프트를 고치는 사고 과정을 보여줘야 한다
대표 실습
1나쁜 프롬프트를 좋은 프롬프트로 바꾸기 — 역할·대상·목표·형식·기준을 추가하며 결과 비교
2프롬프트 체크리스트 만들기 — 역할·대상·목적·자료·형식·기준·후속 7항목 점검
3결과물 개선 루프 — 초안 → 구조 개선 → 표현·분량·대상 맞춤 → 자체 평가
결과물

브라우저로 장난치기

브라우저를 단순한 접속 도구가 아니라, HTML·CSS·JavaScript·브라우저 API를 활용하는 창작·실험·업무 도구로 재발견하는 모듈

강사가 전달할 핵심 메시지
·브라우저는 웹페이지를 보는 도구이면서 동시에 앱 실행 환경이다
·HTML 한 파일만으로도 교육용 실습 도구를 만들 수 있다
·AI에게 코드를 요청하고, 브라우저에서 바로 실행하고, 다시 수정하는 방식은 가장 빠른 바이브코딩 훈련이다
·설치 부담이 적기 때문에 초급자 교육에 특히 적합하다
대표 실습
1HTML 한 파일로 자기소개 앱 — 구조·디자인·이벤트를 한 번에 체험
2브라우저 메모장 — LocalStorage 저장·불러오기·삭제
3CSV 파일 미리보기 — 업로드·표 표시·필터·통계
4음성인식 장난감 — Web Speech API로 받아쓰기
5Canvas 카드뉴스 — 텍스트·배경 조합 후 PNG 다운로드
결과물
· HTML 단일파일 앱 1~3개 · 브라우저 기반 메모장 또는 계산기 · CSV 미리보기 도구 · 카드뉴스 생성기 · 음성인식 메모 도구

강사가 전달할 핵심 메시지

강사가 전달할 핵심 메시지

·AI가 코드를 만들어줘도 사용자는 입력값, 결과물, 오류 메시지를 읽을 수 있어야 한다
·자동화의 핵심은 코딩이 아니라 "반복되는 업무를 절차로 분해하는 능력"이다
대표 실습

2폴더 자동 정리기 — 확장자·날짜 기준 분류·이동
3PDF 병합·분리 도구 — 정렬 후 병합, 특정 페이지 추출
4엑셀 파일 자동 집계 — 여러 파일 통합·중복 제거·요약

문서 자동화

PDF, Word, PPT 같은 문서를 AI와 파이썬으로 읽고, 변환하고, 생성하고, 보고서 형태로 자동화하는 모듈

강사가 전달할 핵심 메시지
·문서 자동화는 "글쓰기 자동화"가 아니라 "문서 생산 공정 자동화"다
·좋은 결과물을 얻으려면 문서의 구조, 입력자료, 출력서식이 분리되어야 한다
·AI는 초안과 구조화에 강하고, 파이썬은 반복 처리와 파일 생성에 강하다

강사 운영 역량

AI 강사가 현장에서 데모를 안정적으로 시연하고, 실습을 운영하고, 질문과 오류에 대응하며, 수강생 결과물을 평가하는 역량을 기르는 모듈

강사가 전달할 핵심 메시지
·AI 강사는 정답을 알려주는 사람이 아니라, 불확실한 상황에서 학습을 이끄는 사람이다
·데모는 짧고 강해야 하며, 실패했을 때의 대안도 준비되어야 한다
·실습은 결과물 중심으로 설계해야 한다
·오류 대응은 강사의 전문성을 보여주는 중요한 순간이다
