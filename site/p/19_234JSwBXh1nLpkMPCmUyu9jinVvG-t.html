CDSA는 공공기관과 기업의 실제 문서·데이터·보안 환경을 먼저 진단하고, 교육 당일 작동하는 산출물을 만드는 방향으로 과정을 구성합니다. 홈페이지는 행정안전부·과학기술정보통신부 자문 경력을 가진 전문가가 커리큘럼을 직접 설계한다고 소개합니다.

핵심 단위는 ‘AI를 배웠다’가 아니라 업무 하나를 끝냈다입니다. 반복 엑셀, 문서·보고, 데이터 분석, 시장조사, 내부 규정 검색, 폐쇄망 자동화처럼 현장의 병목을 찾아 문제정의→구현→검증→재사용까지 연결합니다.

01HTML·CSS·JS 단일 파일 도구브라우저만 있으면 동작합니다. 자바스크립트 라이브러리를 파일 안에 심어 넣어, 더블클릭 한 번으로 실행됩니다. CDN도 설치도 필요 없습니다. 민원 CSV를 올리면 대시보드가 그려지고 통계가 계산됩니다.
02Python 오프라인 패키징외부망에서 코드를 받아 내부망에서 실행합니다. 라이브러리가 필요하면 pip install --target 한 줄로 폴더째 받아 폐쇄망으로 옮기면 끝입니다. 보고서 자동 생성, PDF 추출, 개인정보 마스킹을 한 사람이 한 시간 안에.
03Node.js NPM 오프라인 배포node_modules 폴더째 들고 들어가면 내부망에서도 수천 개의 오픈소스 라이브러리를 그대로 사용할 수 있습니다. 파일 정리, 로그 파싱, 대량 변환 등 더 복잡한 자동화.
04Ollama + 로컬 소형 LLM1B~2B 크기의 모델이면 CPU만으로도 동작합니다. 민원 유형 분류, 자연어 요약, 짧은 질의응답을 전부 로컬에서 외부 통신 없이 수행합니다. 폐쇄망 안의 AI 어시스턴트 완성.
05VBA + Ollama 연동엑셀 VBA에서 로컬 AI 함수를 직접 호출합니다. 셀 하나에 =AI("이 민원을 3줄 요약")이면 됩니다. GPT for Sheets의 공공 버전을 직접 제작.
06내부망 AI 에이전트파일을 읽고, 수정하고, 업무를 함께하는 AI 에이전트를 내부망 안에서 운용합니다. 보안 당국이 검증한 공공 기반 모델을 탑재해 공공형 AI 에이전트 구성.
07내부 문서 질의 (RAG 대체)기관 내부 규정, 지침, 매뉴얼을 대상으로 자연어 질의를 수행합니다. 클라우드 RAG 없이 로컬 임베딩과 벡터 검색으로 구현합니다. 개인정보 외부 유출 위험 없음.

Q. 코딩을 전혀 모르는 직원도 들을 수 있나요?네. 바이브코딩 과정은 비개발자를 전제로 설계했습니다. 자연어로 의도를 전달하면 AI가 코드를 만들고, 수강생은 방향을 잡고 결과를 검증합니다. 실제로 공무원·행정직·기획자·마케터를 대상으로 진행해 왔습니다.
Q. 인터넷이 안 되는 행정망에서도 실습이 가능한가요?가능합니다. 민첩한 AI 거버넌스 8가지 유형이 모두 폐쇄망에서 동작하도록 설계되어 있습니다. 단일 HTML 도구, Python 오프라인 패키징, Ollama 로컬 LLM, VBA+Ollama 엑셀 AI 함수 등을 외부 통신 없이 실행합니다.
Q. 교육이 끝나면 무엇이 남나요?수강생별 실제 동작하는 산출물이 남습니다. 폐쇄망 업무 도구, 클라우드 서비스, 자동화 스크립트, 대시보드, 프롬프트 라이브러리 등이며, 기관 단위 아카이브로 정리해 전달합니다.
Q. AI 도구는 계속 바뀌는데 교육 내용이 금방 낡지 않나요?도구 사용법보다 '새 도구가 나와도 5분 안에 파악하는 루틴'과 아키텍처 설계 역량을 가르칩니다. 도구 목록은 회차마다 갱신합니다.
