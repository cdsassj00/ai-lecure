슬라이드 디자인 시스템

본 가이드는 1~8차시 모든 슬라이드를 동일한 디자인 언어로 제작하기 위한 토큰·레이아웃·컴포넌트 규범이다. 신규 차시 제작 시 본 가이드의 CSS를 그대로 복사하고, 컴포넌트 코드를 조립한다.

1. 디자인 철학

Editorial Warm. 기술 스타트업 랜딩 페이지가 아니라, 학술 저널·고전 출판물의 느낌. 차가운 색(파랑·보라·사이안)은 일절 사용하지 않는다. 모든 색은 따뜻한 크림·잉크·클레이 계열이다.

고밀도 학습 자료. 한 장의 슬라이드가 강의 한 세션의 핵심을 지탱한다. 빈 공간은 부연 해설·사례·통계·체크리스트로 채운다. 3칼럼 레이아웃이 기본이며, 각 칼럼은 바닥(푸터 직전)까지 컴포넌트로 가득 찬다.

세리프 헤드라인 + 산세리프 본문 + 모노스페이스 라벨. 헤드라인은 Fraunces/Noto Serif KR, 본문은 Pretendard, 메타 라벨·코드·숫자는 JetBrains Mono. 이 세 층위가 정보 위계를 만든다.

장식 금지. 이모지·아이콘 폰트·그라디언트 블롭·글래스모피즘·네온 글로우 사용하지 않는다. 정보는 텍스트·표·도형·코드 블록으로만 전달한다.

5. 레이아웃 — 칼럼 계산

본문 영역 너비 = 1440px. 칼럼은 CSS grid를 사용하며 absolute 배치를 금지한다 (이전 깨짐의 원인). 칼럼 간 디바이더는 gap + border로 처리한다.

5.1 3-Column (기본 레이아웃)

/* 본문 영역 전체를 3칼럼 그리드로 */
.bd {
  position: absolute;
  left: 80px; right: 80px;
  top: 210px; bottom: 56px;     /* 638px 높이 */
  display: grid;
  grid-template-columns: 1fr 1fr 1fr;
  gap: 0;
  background: var(--ln2);       /* gap 디바이더 색 */
}
.bd > .col {
  background: var(--bg);
  padding: 14px 18px;
  overflow: hidden;
  display: flex;
  flex-direction: column;
}
/* gap: 0 + background 조합으로 1px 디바이더 효과 */
/* 실제 gap이 필요하면 gap: 1px (= 1px 디바이더) */
핵심 변경: 이전 버전에서 칼럼을 position:absolute로 배치해서 너비 계산이 틀어졌다. 이제 display:grid 기반으로 전환한다. 칼럼 비율이 다를 경우 grid-template-columns: 460px 500px 460px 같이 px로 명시하되, 합이 반드시 1440 - (gap × 2)와 일치해야 한다.

5.2 비균등 3-Column

/* 예: 좁은-넓은-좁은 */
grid-template-columns: 420px 1fr 420px;  /* 가운데가 나머지 차지 */

/* 예: 넓은-좁은-좁은 */
grid-template-columns: 560px 440px 438px; /* gap:1px이면 합=1438 */

5.3 2-Column

grid-template-columns: 1fr 1fr;      /* 균등 */
grid-template-columns: 1.3fr 1fr;    /* 좌 넓게 */
grid-template-columns: 1fr 80px 1fr; /* 가운데 브릿지 (외부/내부망) */

5.4 1-Column (표 전용, Cover 등)

/* 그리드 없이 단일 flex column */
.bd { display: flex; flex-direction: column; }

DODON'T
3칼럼 기본. 각 칼럼에 4~6개 컴포넌트1칼럼에 1개 컴포넌트만 놓기

최소 1개 다크 블록(cod 또는 dstrip) 포함크림·크림·크림 — 단조로운 밝은 톤 반복
표·다이어그램·코드 등 비텍스트 컴포넌트 최소 1개본문 텍스트만으로 칼럼 채우기
Section Header → Body → Callout/Table → Pitfall/Checklist 순서 유지순서 없이 컴포넌트 배치

12. 자가 점검 체크리스트

슬라이드 1장 완성 후 아래 항목을 확인한다.

#점검 항목
1슬라이드 사이즈가 1600×900 인가
2다크 헤더바(52px)가 있는가
3크림 푸터바(52px)가 있는가
4헤드라인 블록 4요소(kicker·h1·lede·bar)가 모두 있는가
5본문이 grid 기반 칼럼으로 구성됐는가 (absolute 금지)
6각 칼럼에 4개 이상 컴포넌트가 있는가
7칼럼 하단이 비어 있지 않은가
8본문 텍스트가 13px인가 (15px 이상 금지)
9최소 1개 다크 블록(cod/dstrip)이 있는가
10Editorial Warm 팔레트만 사용했는가 (차가운 색 금지)
11출처·캡션이 필요한 곳에 모두 있는가
12hbar·fbar 메타데이터가 정확한가
