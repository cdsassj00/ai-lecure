이 과정이 만들어진 배경

2026년 상반기에 전국 8개 거점기관을 전수 방문하여 4시간씩 현장 교육을 진행했습니다. NotebookLM, Antigravity, 엑셀 함수와 VBA, 바이브코딩을 다뤘고, 교육 이후 6명이 본인 업무에 쓸 웹앱을 직접 만들어 배포했습니다. 코딩을 배운 적 없는 분들이 만든 결과물입니다.

다만 4시간은 짧았습니다. 개념을 이해하고 아이디어를 잡는 데까지 가면 시간이 끝났고, 실제로 돌아가는 도구를 완성하는 데까지는 닿지 못한 경우가 많았습니다. 방문 교육이 끝나고 사무실로 복귀하면 이어서 진행되지 못했습니다.

그래서 하반기는 집체 프로젝트 교육으로 바꿨습니다. 한자리에 모여 이틀 동안 이어서 만들고, 강사 2인이 옆에서 붙어서 막히는 지점을 바로 풀어 드립니다. 교육이 끝나는 시점에 실제로 동작하는 도구를 확보하는 것이 이 과정의 목표입니다.

이 과정에서 다루지 않는 것

  • 프로그래밍 언어 문법. 변수·반복문·함수를 외우지 않습니다.
  • 코드를 손으로 작성하는 연습. 코드는 에이전트가 씁니다.
  • AI 일반론과 원리 설명. 이틀 내내 도구와 결과물만 다룹니다.
이 과정에서 배우는 것은 코딩이 아니라 재료를 고르는 판단입니다. 작업을 지시하려면 그 작업이 무엇으로 처리되는지는 알아야 하지만, 직접 만들 줄 알 필요는 없습니다. 이 과정은 재료를 구분하는 기준을 익히는 과정입니다.

HTML 파일 하나로 동작하는 구조

에이전트에게 입력 폼을 만들어 달라고 하면 .html 파일 하나가 나옵니다. 그 파일을 더블클릭하면 브라우저가 열리면서 화면이 뜹니다. 설치도 배포도 서버도 필요 없습니다.

옆자리에 그 파일 하나를 메신저로 보내면, 받은 사람도 더블클릭만 하면 똑같이 씁니다. 프로그램을 나눠 주는 가장 간단한 방법입니다.

HTML을 고르는 세 가지 신호

  1. 사람이 보는 화면이 필요합니다 — 입력하거나, 조회하거나, 점검하는 화면입니다
  2. 설치를 시킬 수 없습니다 — 여러 사람에게 나눠 줘야 하는데 각자 설치는 무리입니다
  3. 현장에서 씁니다 — 태블릿이나 휴대폰에서도 열려야 합니다

JSON 구조

돌아오는 답의 구조 (값은 매일 달라집니다)
{
  "latitude": 35.82,
  "longitude": 127.15,
  "timezone": "Asia/Seoul",
  "daily_units": {
    "temperature_2m_max": "°C",
    "precipitation_sum": "mm"
  },
  "daily": {
    "time":                ["2026-09-29", "2026-09-30", "2026-10-01"],
    "temperature_2m_max":  [24.3, 25.1, 22.8],
    "temperature_2m_min":  [14.2, 15.0, 13.6],
    "precipitation_sum":   [0.0, 2.4, 11.2]
  }
}

JSON 읽는 규칙 3가지

  1. 이름: 값 형태로 되어 있습니다. "latitude": 35.82 는 위도가 35.82라는 뜻입니다.
  2. 중괄호 { } 는 묶음입니다. daily 안에 일별 데이터가 모여 있습니다.
  3. 대괄호 [ ] 는 목록입니다. 순서가 서로 대응합니다. time의 첫 번째 날짜와 temperature_2m_max의 첫 번째 값이 짝입니다.

이 파일들이 생기는 이유

코딩 에이전트는 작업하면서 스스로 메모를 남깁니다. 무엇을 만들기로 했는지, 어떤 규칙을 지켜야 하는지를 파일로 적어 두고 다음에 다시 읽습니다. 사람이 인수인계 문서를 쓰는 것과 같은 이유입니다.

여러분이 이 파일들을 직접 쓰거나 고치실 필요는 없습니다. 폴더에 낯선 파일이 보이더라도 지우지 마시고 그대로 두시면 됩니다.

불필요한 파일 정리

작업이 끝난 뒤 __pycache__ 같은 임시 폴더는 지우셔도 됩니다. 다만 .venv 폴더는 이 도구가 쓰는 프로그램들이 들어 있는 곳이라 지우면 다시 설치해야 합니다.

파일 이름 앞에 점(.)이 붙은 것은 뭔가요설정 파일입니다. 평소에는 숨겨져 있고 건드리지 않으셔도 됩니다.
