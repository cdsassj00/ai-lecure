08Claude Code · 실제 실행되는 컴퓨터 선택

Claude Code는 내 PC 전용 도구가 아니라, 실행장소를 선택하는 코드 작업 시스템입니다

같은 Desktop UI에서도 Local·Remote·SSH·WSL에 따라 명령이 실제로 도는 컴퓨터가 달라집니다.
CLAUDE CODE
LOCAL · REMOTE · SSH · WSL
LOCAL내 PC

내 컴퓨터에서 실행하며 선택한 폴더의 파일과 설치된 도구에 직접 접근합니다. 모델의 판단 처리는 Anthropic 서비스와 통신합니다.

명령: 내 운영체제(OS) · 파일: 내 PC 코드 저장소 · 셸/테스트: 내 PC
REMOTE / WEBAnthropic VM

세션마다 새 관리형 가상컴퓨터(VM)에 저장소를 복제(clone)해 실행합니다. 앱이나 PC를 닫아도 백그라운드에서 계속할 수 있습니다.

명령: 격리 VM · 파일: 저장소 복제본 · 결과: 작업 가지(branch)/변경점(diff)/병합 요청(PR)
SSH내 서버

Desktop은 조작 화면이고 Claude Code는 SSH(원격 명령 접속)를 통해 내가 관리하는 서버·클라우드 VM·개발 컨테이너에서 실행됩니다.

명령/파일: 원격 서버 · 권한: 그 서버에 로그인한 계정
WSL 2내 PC Linux

Windows 안에 마련한 Linux 환경인 WSL 배포판에서 Linux 도구 묶음과 경로를 사용합니다. 일반 Windows Local과는 별도 실행장입니다.

명령: WSL · 파일: Linux/연결된 Windows 경로 · 도구: Linux용
설정은 어디까지 따라가는가

개인 설정·skills는 ~/.claude/에 있습니다. Remote/Web VM에는 자동 복제되지 않습니다. 공유하려면 CLAUDE.md와 .claude/를 코드 저장소(repo)에 변경 기록으로 저장(commit)합니다.

권한·샌드박스

기본은 읽기 전용이며, 편집·Bash 명령은 승인이 필요합니다. 작업 폴더 경계와 선택적 /sandbox로 파일·네트워크 범위를 제한합니다.

Work/Cowork vs Codex/Claude Code

차이는 GitHub·병합 요청(PR)·분리 작업 폴더(worktree) 하나가 아닙니다. 업무 문서·온라인 업무서비스(SaaS)를 검증하는 하네스와 코드 저장소·명령·테스트·변경점을 검증하는 하네스의 차이입니다.
