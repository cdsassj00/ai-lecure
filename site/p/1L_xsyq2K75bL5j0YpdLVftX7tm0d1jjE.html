CANVAS · AGENT MODE편집 작업 공간 + 멀티스텝 자동
CANVAS편집 공간
채팅 옆에 열리는 편집 작업 공간 — 문서·코드를 나란히

특정 구간만 하이라이트해서 수정 요청 가능. Claude Artifacts, Cursor와 유사. 공공: 보고서 초안을 Canvas에서 작성하면서 실시간 AI 수정.

AGENT MODE ★Plus/Pro
멀티스텝 작업을 자동 수행 — Drive 검색→정리→보고서

Google Drive에서 파일을 가져오고, 웹을 검색하고, 결과를 정리하는 등 여러 단계를 순차 실행. Canvas와 달리 외부 도구 연결 가능. 유료 플랜.

CANVAS vs AGENT MODE
Canvas = 문서 편집 협업 / Agent = 도구 연결 자동화

Canvas는 외부 연결 불가. Agent Mode는 Drive·웹·API 연결 가능. 용도가 다르다.

DEEP RESEARCH · o3종합 리서치 + 추론 모델
DEEP RESEARCH종합 리포트

MEMORY개인화
대화에서 사용자 정보를 기억 → 다음 대화에 반영

프로젝트별 메모리 설정 가능. 사용자 완전 제어(삭제·수정). 공공: "내가 ○○부서 주무관이고 담당 업무는 △△" 한 번만 알려주면 이후 자동 반영.

ARTIFACTS · COMPUTER USE실시간 렌더링 + 화면 제어
ARTIFACTS실시간 미리보기
코드·문서·시각화를 별도 패널에 렌더링

React·HTML·Mermaid·SVG를 실시간 미리보기. ChatGPT Canvas와 유사하지만 코드 실행 결과를 즉시 렌더링하는 점이 차별화. 공공: 데이터 시각화를 즉석 생성해 보고서에 삽입.

COMPUTER USE실험적
에이전트가 화면을 보고 마우스·키보드를 직접 조작

레거시 시스템(온나라, 새올 등)과 AI를 연결하는 가능성. 아직 실험적이지만 API가 없는 시스템도 AI가 조작할 수 있다는 것이 핵심. 6차시에서 다시 다룸.

CLAUDE vs CHATGPT · 판단 기준
장문·법령·코드 → Claude / 도구 연결·검색 → ChatGPT

Claude: 200K 컨텍스트, 추론 정합성, 코드 품질. ChatGPT: Agent Mode, Deep Research, Workspace 연동. 업무 특성에 따라 선택.

PITFALL
▸ 한국어 관용 표현이 간혹 부자연스러움
Styles에서 "한국어 공문서 톤"을 설정하면 상당 부분 해결된다.
DEMO · 실제 화면시연 시 보여줄 것
시연 1. Projects에 법령 PDF 업로드 → 질의응답

법령 전문 PDF를 프로젝트에 업로드하고 "제3조 2항의 의미를 설명해줘"와 같은 질문. 200K 컨텍스트의 위력을 체험.

시연 2. Skills 설정 화면

Settings → Skills 메뉴에서 기존 스킬 목록 확인. "이 스킬을 부서 동료에게 어떻게 배포하는가" 절차 설명.

시연 3. Artifacts 데이터 시각화

"이 CSV 데이터로 부서별 민원 건수 차트를 그려줘" → Artifacts 패널에서 즉시 렌더링. 코드 수정 → 즉시 반영.

KEY INSIGHT · 거점리더 시나리오
Skills + Styles = 부서 표준 AI 환경

거점리더가 "민원 답변 스킬" + "공문서 스타일"을 세팅해두면, 동료는 프로젝트에 들어가서 질문만 하면 된다. AI 숙련도가 낮은 동료도 일관된 품질의 산출물을 받을 수 있다.
