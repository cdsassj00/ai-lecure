한국보건복지인재원 검토용 · 2026년 9월 12일

1 개발 목적과 범위

보건·복지 현장에서 접하는 업무자료를 활용해 AI로 콘텐츠를 작성하고, 데이터를 분석하며, 업무에 필요한 도구를 구현하는 실습데이터 8세트를 개발하고자 합니다. 공개자료와 교육용으로 직접 제작한 업무자료를 함께 구성하여 충분한 실습량과 현장 활용성을 확보하겠습니다.

실습데이터는 행정업무 자동화, 정책 의사결정, 사업 운영 개선 등 자신의 업무에 AI를 활용하는 교육의 공통 자료로 개발합니다. 인증평가 대비는 그 활용 방식 중 하나입니다. 같은 자료로 시험에 없는 강의 활동도 구성할 수 있으며, 문제세트로 선정되지 않은 후보에서 확보한 자료도 검토 상태와 이용조건에 맞춰 교육에 활용할 수 있습니다. 평가용으로 구성하는 8세트는 공통된 문제·평가 구조로 정리하고 향후 시험플랫폼에 JSON으로 등록할 수 있도록 준비하겠습니다.

분야 그린 블루 합계
보건 2세트 2세트 4세트
복지 2세트 2세트 4세트
합계 4세트 4세트 8세트

세트당 콘텐츠·데이터분석·서비스구현의 3과목을 기준으로 총 24개 과목별 문제를 구성합니다. 그린은 안내된 조건에 따라 자료를 활용하고 결과를 만드는 실습, 블루는 여러 자료를 연결하여 대안을 비교하고 결과를 검증하는 실습을 중심으로 난도를 설계하겠습니다. 세부 난도와 도구 범위는 교육·평가 운영 기준에 맞춰 확정합니다.

주제 선정 방식은 분야·등급별 5개씩 총 20개 후보를 검토한 후, 중간보고 협의를 통해 각 구분에서 2개씩 선정하는 안입니다. 본 계획의 우선 검토 8개 주제는 제안이며 최종 개발 주제는 아닙니다.

2 개발 방향

현장 업무를 중심으로 실습을 구성합니다

사업안내, 기관 현황, 신청서, 일정표, 상담·회의 기록 등 실제 업무에서 사용하는 자료 구조를 반영합니다. 학습자는 주어진 상황에서 필요한 정보를 찾고, 여러 조건을 판단하여 업무 결과물을 완성합니다.

세트별 수행 과정과 결과물을 다르게 설계합니다

문서 비교나 통계 수치 확인을 모든 세트에 반복 적용하지 않습니다. 대상별 교육 콘텐츠 제작, 일정 편성, 공간 분석, 조건별 실험, 수요와 공급의 매칭, 예약·대기 관리, 사례 처리 흐름, 근거 기반 검색 등으로 수행 유형을 분산합니다.

주제 선정 시 업무 대상·입력자료·수행 절차·최종 결과물을 비교하겠습니다. 네 요소 중 세 요소가 유사한 조합은 재설계를 검토합니다. 요약·정리·기초 집계 등 필요한 공통 기능은 활용하되, 도구나 주제명만 바꾼 실습이 되지 않도록 하겠습니다.

기존 개발 소재와의 중복을 확인합니다

보건복지부·질병관리청·식품의약품안전처의 기개발 세트와 주제명뿐 아니라 업무 대상, 원자료, 핵심 과제를 대조합니다. 중복 검토 결과와 후보 간 유형 비교표를 함께 제시하여 최종 주제를 선정하겠습니다.

3 자료 확보와 실습파일 제작

제공받은 수요조사 결과와 공개데이터는 주제 선정과 업무 맥락 파악의 근거로 활용합니다. 실제 수행에 필요한 자료가 부족한 경우에는 공개 원문을 추가 확보하고 교육용 업무자료를 직접 제작하겠습니다.

자료 구분 구성 내용 활용 목적
공식 근거자료 공개 사업안내, 지침, 통계, 기관 현황, 공식 서식 제도·용어·업무 절차의 근거 확보
교육용 업무자료 가상 신청서, 설문, 일정표, 회의록, 상담 기록, 이미지, 업무 이력 충분한 실습량과 다양한 판단 상황 제공
강사용 검증자료 기준 답안, 예시 결과물, 평가 기준, 검증용 입력과 결과 풀이 설명과 일관된 평가 지원

제작 규모는 학습 목표와 실제 수행시간을 기준으로 조정합니다. 문서 중심 실습은 원문·업무문서·표·이미지 등 실질적인 자료 12~20개를 기본 목표로 합니다. 데이터 중심 실습은 그린 1,000~5,000행, 블루 10,000~50,000행 또는 서로 연결된 여러 표를 계획하되, 공간자료나 복합 사례처럼 행 수보다 관계의 복잡성이 중요한 경우에는 별도 기준을 적용합니다. 이는 제작 목표이며 완료 수량이나 일률적인 최소 납품 규격은 아닙니다.

가상자료는 교육용임을 표시하고 실제 공개자료와 구분합니다. 같은 업무 상황을 기준으로 문서·표·이미지를 제작하여 식별번호, 날짜, 수량, 처리 상태가 서로 맞도록 검증합니다. 실제 지침이나 제도 기준을 임의로 만들거나 실제 기관에 가상의 실적을 부여하지 않습니다.

현재 준비 현황으로는 추가 공개자료 원본 21개를 확보했습니다. 보건 10개, 복지 11개이며, PDF 16개와 CSV 2개, XLSX 1개, HWP 2개로 구성됩니다. 같은 내용의 다른 파일 형식이 포함된 수량입니다. 지역아동센터 CSV 1,965행, 치매센터 CSV 317행과 통합돌봄·자활사업·지역아동센터 사업안내 등이 포함되어 있습니다. 자료별 판본, 내용 적합성, 이용조건은 최종 실습자료 선정 시 확인하겠습니다.

4 우선 검토 주제와 과목 구성

아래 8개 주제는 유형 다양성과 자료 제작 가능성을 고려한 우선 검토안입니다. 원자료 확보, 기존 소재 중복, 교육환경 검토 결과에 따라 부록의 예비 후보로 조정할 수 있습니다.

보건 분야 주제 콘텐츠 데이터분석 서비스구현
그린 건강생활 실천 캠페인 대상별 카드뉴스와 교육 이야기 구성 주민 자유응답 분류와 대상군 도출 선택에 따라 진행되는 참여형 교육 콘텐츠
그린 방문건강관리 운영 회의·변경요청 기반 실행계획 작성 인력·가용시간 조건별 운영안 비교 일정 편성과 캘린더 파일 생성
블루 치매 지원자원 배치 지역자원 개선 대안 설명 위치·거리 기반 지원 공백 분석 자료 결합과 대안별 지도 생성
블루 당뇨병 집계자료 활용 분석 설계와 결과 해석 작성 결측·비공개 값 처리 가정에 따른 결과 비교 조건별 분석 반복 실행과 결과 기록
복지 분야 주제 콘텐츠 데이터분석 서비스구현
그린 자활기업 판로 지원 상품·서비스 제안자료 구성 구매 수요와 공급 조건 매칭 대상별 제안서 일괄 생성
그린 지역아동센터 프로그램 운영 신청서·공지 기반 운영자료 작성 시간대별 수요와 대기 현황 분석 예약·취소·대기 순번 처리
블루 아동 통합사례관리 상담·점검 기록의 사건 이력 구성 단계별 지연과 누락 분석 조건·기한에 따른 업무 상태 처리
블루 통합돌봄 기관 협업 여러 지침을 연결한 근거 자료 구성 기관 간 의뢰 흐름과 서비스 공백 분석 출처 제시와 근거 부족 시 응답 보류 기능

방문건강관리 일정과 아동 사례는 교육용 가상 업무기록으로 구성합니다. 당뇨병 실습은 공개 집계자료와 별도의 가상 실험자료를 사용하며 비공개 값을 복원하지 않습니다. 치매 자원과 통합돌봄 검색은 자료의 기준일·판본 및 실습환경 검증을 거쳐 범위를 확정합니다.

5 문제와 평가자료의 공통 구조

행정안전부 문제세트의 정리 체계를 참고하여 모든 과목을 같은 작성 항목으로 관리하겠습니다. 이 공통 구조는 강사의 자료 확인, 문항 검토, 플랫폼 등록을 위한 기준이며, 세트별 실습 방식은 각 업무에 맞게 설계합니다.

작성 항목 포함할 내용
업무 시나리오 담당자 역할, 업무 상황, 과제의 목적
제공 자료 첨부파일 목록, 자료의 역할, 실제·가상 구분
수행 과제 처리할 작업, 적용 조건, 필요한 판단
제출 요구 입력할 답 또는 제출 파일, 형식과 필수 항목
평가 기준 배점, 정답 또는 평가표, 허용오차와 부분점수
답안과 해설 기준 결과물, 근거, 풀이 절차와 확인 방법

수치·조건 충족 여부처럼 정답을 고정할 수 있는 항목은 자동채점 가능 여부를 검토합니다. 기획안·설명자료·프로그램처럼 여러 정당한 결과가 가능한 과제는 근거의 정확성, 요구사항 충족, 대상 적합성, 기능 동작 등을 평가하는 기준을 마련합니다.

플랫폼 등록자료는 검토 원고를 기준으로 신규 등록용 JSON, 편집용 JSON, 첨부파일 묶음을 생성하는 방식으로 준비합니다. 문제 본문, 제출 항목, 배점, 정답 및 첨부 연결이 서로 일치하는지 확인하겠습니다. 시범 세트에서 실제 가져오기 형식과 지원되는 제출·채점 기능을 확인하고, 운영환경에서 가능한 범위를 확정합니다.

학습자에게 제공하는 문제·첨부와 강사·채점자용 답안·해설·검증자료는 구분하여 배포합니다.

6 추진 절차와 일정안

먼저 공통 작성·등록 형식을 정리하고 후보별 수행 과제와 자료 제작 계획을 구체화하겠습니다. 주제 협의 후 시범 1세트로 문제·첨부·답안·JSON의 전체 구성을 검증하고, 다른 등급 1세트를 추가 검증하여 그린·블루의 적정 난도와 수행시간을 점검하겠습니다. 시범 2세트는 최종 8세트에 포함하는 계획입니다.

단계 주요 작업 검토 결과물 예상 작업일
1 주제와 구성 협의 20개 후보 비교, 기존 소재 중복 검토, 8세트 선정 주제·과목별 수행 과제 확정표 1~2일
2 자료와 제작 기준 정리 추가 원문 확보, 파일 구성·평가 기준·등록 양식 정리 자료 목록과 세트별 제작 명세 2~4일
3 시범 세트 제작 1세트 전체 구성 검증 후 다른 등급 1세트 추가 시범 2세트와 실행·등록 검증 기록 4~6일
4 시범 검토 반영 난도, 수행시간, 자료량, 평가·환경 문제 조정 수정안과 공통 제작 기준 1~2일
5 본 제작 나머지 6세트 제작, 매뉴얼 병행 작성 세트별 문제·첨부·답안·해설 12~18일
6 최종 검수와 전수 준비 8세트 교차 검수, 매뉴얼·등록자료 정리, 시연 점검 최종 배포본과 전수용 자료 4~6일
합계 검토 대기시간을 제외한 순차 작업 기준 8세트와 관련 산출물 24~38일

위 기간은 초안의 작업량 추정이며 확정 납기나 현재 시점의 잔여 작업일을 의미하지 않습니다. 투입 인력, 주제 확정일, 검토 회신 일정과 플랫폼 접근 조건을 반영하여 착수 시 세부 일정을 협의하겠습니다.

전수 강의는 요청된 2026년 10월 28일을 기준으로 준비하며, 10월 21일 시연본 고정을 협의 목표로 제안합니다. 주제 확정과 시범 검토를 앞당겨 이후 수정 범위를 관리하고, 해당 목표의 실현 가능성은 세부 일정 수립 시 확인하겠습니다.

7 품질 검수와 강사 전수

10-2 공개 API 응답을 시설 현황 자료와 연결하기

  • 도구 예시: 공개 API·Python·JSON
  • 사용할 자료: 시설 현황 + 교육용 API 응답 표본*
  • 실습 과정: 응답 항목을 현황표와 맞추고 갱신 시각·오류·중복을 기록한다. 계정 준비 전에는 저장된 응답 표본으로 같은 처리 흐름을 실습한다.
  • 완성 결과물: 자료 갱신 도구·통합 현황·오류 기록

10-3 내가 정리한 사업 자료를 AI의 조회 도구로 만들기

  • 도구 예시: MCP·SQLite·함수
  • 사용할 자료: 사업 조건 DB·기관 목록·테스트 질문*
  • 실습 과정: 사업 검색·서류 조회·기관 조회 함수를 만들고 MCP 도구로 연결한다. 자연어 질문에서 적절한 함수를 호출하는지 확인한다.
  • 완성 결과물: 업무 조회 도구·호출 결과·테스트 기록

10-4 분석·작성·검토 역할을 나눠 보고 묶음 완성하기

  • 도구 예시: 에이전트 오케스트레이션
  • 사용할 자료: 사업안내 + 가상 실적·보고 양식·검수 기준*
  • 실습 과정: 분석 역할이 계산표를, 작성 역할이 보고서와 발표자료를, 검토 역할이 원본 대조표를 만든다. 역할 간 파일을 연결하고 오류 부분만 재작업한다.
  • 완성 결과물: XLSX·보고서·발표자료·검토 기록

입문자는 제공 파일로 결과물을 생성하고 원본과 대조합니다. 활용 단계에서는 여러 자료와 도구를 연결합니다. 심화 단계에서는 다음 자료로 재실행하고 오류 처리·검색 품질·저장·권한을 확인합니다. 도구 설치 여부와 수업시간에 따라 한 모듈 실습 또는 연속 과제로 운영할 수 있습니다.

자료 개발에 반영할 사항: 공통 원본·정제본·데이터 사전·출처/판본 정보에 더해, 선택한 교육 활동에 필요한 가상 기록·업무 양식·예외 사례·검토 기준을 준비합니다. 문제세트로 선정되지 않은 후보에서 확보한 자료도 사용조건과 품질을 확인해 교육에 활용할 수 있습니다. 개인 기록·예산·예측 수요 등은 교육용 가상자료로 구분하고, 모의 분석 결과를 실제 정책 효과나 개인의 서비스 자격으로 해석하지 않습니다.
